ValheimRAFT add-on for the Valheim World Editor
===============================================

Shows the ships and land vehicles ValheimRAFT builds in the Valheim World Editor, whole, as the mod builds them,
with their swivels, sails, ropes, rope ladders and what they carry, and moves, copies and deletes each one as one,
in a saved world or live.

Install: put this ValheimRAFT folder in the "addons" folder next to the editor (on macOS, next to
ValheimWorldEditor.app), so that it holds addons/ValheimRAFT/worldeditor.json. Needs the Valheim World
Editor 1.110.0 or later (and WorldEditorBridge 1.110.0 or later in the game for live editing). The add-on
is used while ValheimRAFT (ValheimRAFT.dll) is in one of the BepInEx plugins folders the editor knows;
Settings lists it under Add-ons.

ValheimRAFT itself stays where it is, in BepInEx/plugins: this add-on only teaches the editor about it.
