Tunnelheim add-on for the Valheim World Editor
==============================================

Shows the tunnels Tunnelheim digs in the Valheim World Editor, as the game builds them.

Install: put this Tunnelheim folder in the "addons" folder next to the editor (on macOS, next to
ValheimWorldEditor.app), so that it holds addons/Tunnelheim/worldeditor.json. Needs the Valheim World
Editor 1.98.0 or later. The add-on is used while Tunnelheim (ValheimTunneling.dll) is in one of the
BepInEx plugins folders the editor knows; Settings lists it under Add-ons.

Tunnelheim itself stays where it is, in BepInEx/plugins: this add-on only teaches the editor about it.

https://github.com/Shuiei/valheim-world-editor/tree/main/addons/Tunnelheim
