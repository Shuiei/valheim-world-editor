Expand World add-on for the Valheim World Editor
================================================

Generates, draws and predicts worlds in the Valheim World Editor as the Expand World mods (Expand World Size, Rivers
and Data, by JereKuusela) make them, from the mods' settings and data files.

Install: put this ExpandWorld folder in the "addons" folder next to the editor (on macOS, next to
ValheimWorldEditor.app), so that it holds addons/ExpandWorld/worldeditor.json. Needs the Valheim World Editor
1.106.0 or later. The mods are read from the first BepInEx folder the editor knows that has any of them; Settings
lists the add-on under Add-ons, with its switch.

The mods themselves stay where they are, in BepInEx/plugins: this add-on only teaches the editor about them.
