Riverheim add-on for the Valheim World Editor
=============================================

Opens worlds made with Riverheim in the Valheim World Editor, drawn by your own Riverheim, and makes new ones
with it.

Install: put this Riverheim folder in the "addons" folder next to the editor (on macOS, next to
ValheimWorldEditor.app), so that it holds addons/Riverheim/worldeditor.json. Needs the Valheim World Editor
1.104.0 or later, 1.119.3 or later for the worlds Riverheim 1.3 and later save. The add-on is used while Riverheim
(Riverheim.dll) is in one of the BepInEx plugins folders the editor knows; Settings lists it under Add-ons, with its
switch. Riverheim 1.3 and later need Worldhalla in the same BepInEx folder, as in the game.

Riverheim itself stays where it is, in BepInEx/plugins: this add-on only teaches the editor about it.

https://github.com/Shuiei/valheim-world-editor/tree/main/addons/Riverheim
