Looking for Valheim…
Connect to a server
The server needs BepInEx and the WorldEditorBridge plugin (in the plugin folder next to this program; step-by-step guide). The editor logs in with SSH and connects to the plugin through its own encrypted tunnel: no ssh command to type. After the first connection the server (with its token) is saved for one-click access.

Settings: folders on this computer

Valheim game folder

The folder with valheim_Data. Used for the game's look, and to find BepInEx for "My game".

BepInEx folders

Where else to look for the plugin for "My game": a BepInEx folder, a mod manager profile, or a folder of profiles (a mod manager with its own data folder). The Valheim folder and the default r2modman / Thunderstore Mod Manager profiles are always searched.

World folders
