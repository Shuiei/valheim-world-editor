# ปุ่มลัด

ทุกปุ่มและการใช้เมาส์ ของเอดิเตอร์ จัดกลุ่มตามสิ่งที่คุณกำลังทำ ปุ่ม **?** ในแถบด้านบน (หรือ `F3`)
แสดงปุ่มหลักๆ ขณะที่คุณทำงาน

ปุ่มลัดใช้ได้เฉพาะในเอดิเตอร์ 3D: ไม่ทำงานขณะที่คุณพิมพ์ในช่อง และไม่ทำงานที่หน้าเริ่มต้น หรือแผนที่โลก
(ยกเว้น `F1`: ใช้ได้ทุกที่) บน
Mac ให้กด `Cmd` ทุกที่ที่หน้านี้เขียนว่า `Ctrl` (`Cmd+Z` เลิกทำ `Cmd`+คลิก เพิ่มในการเลือก) และกด `Option` แทน
`Alt`

## กล้อง

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| ลากปุ่มขวา | หมุนมุมมอง ในโหมดเดินและบิน: มองไปรอบๆ |
| ล้อเมาส์ | ซูม ตั้งแต่ 3 m ถึง 3 km จากจุดที่คุณมอง |
| ลากปุ่มกลาง | เลื่อนมุมมอง |
| `Space` + ลากปุ่มซ้าย, `Shift` + ลากปุ่มขวา | เลื่อนมุมมอง ในเครื่องมือใดก็ได้ (สะดวกเมื่อไม่มีปุ่มกลาง) |
| ลากปุ่มซ้าย (เครื่องมือ **มุมมอง**) | เลื่อนมุมมอง |
| `W` `A` `S` `D` หรือปุ่มลูกศร | เคลื่อนที่ไปรอบๆ ยิ่งซูมออกไกล ยิ่งเร็ว ไม่ทำงานขณะกด `Ctrl` หรือ `Alt` ค้าง |
| `F` | เดินที่ระดับสายตา แล้วบิน แล้วกลับสู่มุมมองปกติ ในทุกเครื่องมือ |
| `Shift` (เดิน) | วิ่ง: 12 m/s แทน 6 |
| `Space` / `C` (บิน) | ขึ้น / ลง ทะลุพื้นดินได้ด้วย (เข้าไปในอุโมงค์ และห้องใต้ดินของม็อด) `Shift`: 45 m/s แทน 15 |

ขณะเดินหรือบิน ล้อเมาส์จะไม่ซูม และการลากจะไม่เลื่อนมุมมอง ดู
[เดินและบิน](../editor-basics.md#เดนและบน)

## แผงและการบันทึก

| ปุ่ม | การกระทำ |
|---|---|
| `V` | เปิดหรือปิดแผง **มุมมอง** |
| `L` | เปิดหรือปิด **ประวัติ** |
| `?` (`Shift+/`) หรือ `F3` | เปิดหรือปิดการ์ดวิธีใช้ **การควบคุม** |
| `F1` | หน้าต่างวิธีใช้ ที่หน้าของเครื่องมือที่ใช้อยู่ (ดู [หน้าต่างวิธีใช้](#หนาตางวธใช)) **?** เล็กๆ ที่ด้านบนของแต่ละแผง เปิดหน้าของแผงนั้น |
| `Ctrl+S` | **บันทึกลงโลก** (โลกที่บันทึกไว้) **นำไปใช้แบบไลฟ์** (ไลฟ์) **บันทึกพิมพ์เขียว** (เวิร์กช็อป) |

## เลือกเครื่องมือ

| ปุ่ม | เครื่องมือ |
|---|---|
| `1` `2` `3` `4` `5` | ยกขึ้น กดลง ปรับราบ เกลี่ย คืนสภาพ |
| `0` | ธรรมชาติ |
| `O` (ตัวอักษร) | กัดเซาะ |
| `6` `7` `8` `9` | แปรง **ระบาย** แบบ ดิน พรวนดิน ปูหิน ล้างการระบาย |
| `B` | ขอบเขต |
| `P` | เส้นทาง |
| `T` | จัดวาง (**ก่อสร้าง** ในเวิร์กช็อป) |
| `U` | ก่อสร้าง |
| `G` | ภูมิประเทศ |
| `E` | เลือก |
| `M` | วัด |
| `H` หรือ `Esc` | มุมมอง (`Esc` เฉพาะเมื่อไม่มีอย่างอื่นให้ยกเลิก ดู [Esc ทำงานอย่างไร](#esc-ทำงานอยางไร)) |

ปุ่มตัวเลขบนแป้นตัวเลข ก็ใช้ได้ **ดันเจี้ยน** **สคริปต์** และ **แบบแปลน** ไม่มีปุ่มลัด:
คลิกบนแถบเครื่องมือ ในเวิร์กช็อป มีเพียง `U` หรือ `T`, `E` และ `H` หรือ `Esc` ที่ใช้เลือกเครื่องมือ

## เลิกทำ คัดลอก และวาง

| ปุ่ม | การกระทำ |
|---|---|
| `Ctrl+Z` | เลิกทำการเปลี่ยนแปลงล่าสุด |
| `Ctrl+Y` หรือ `Ctrl+Shift+Z` | ทำซ้ำ |
| `Ctrl+C` | คัดลอกกล่อง หรือรูปหลายเหลี่ยมของ ขอบเขต หรือวัตถุที่เลือก (เครื่องมือ ขอบเขต และ เลือก) |
| `Ctrl+X` | ตัด: คัดลอกแบบเดียวกัน แล้ววัตถุจะออกจากโลก เป็นขั้นตอนเดียว (พื้นดินยังอยู่) |
| `Ctrl+V` | เริ่มวางสิ่งที่อยู่ในคลิปบอร์ด จากเครื่องมือใดก็ได้ |
| `[` / `]` | ขนาดแปรง เล็กลง / ใหญ่ขึ้น 1 m (1 ถึง 30 m) |

## เลือกวัตถุ

ใช้ได้ในเครื่องมือ **เลือก** (`E`) การคลิกในเครื่องมือ **มุมมอง** ก็เลือกวัตถุได้แบบเดียวกัน

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| คลิก | เลือกวัตถุนั้นเพียงอย่างเดียว คลิกอีกครั้งที่จุดเดิม: วัตถุถัดไป ที่อยู่ด้านหลัง |
| `Ctrl`+คลิก | เพิ่มวัตถุ หรือเอาออก หากเลือกไว้แล้ว |
| `Shift`+คลิก | เอาวัตถุออกจากการเลือก |
| `Ctrl+Shift`+คลิก | เพิ่มวัตถุที่แสดงอยู่ทุกชิ้น ในแถวเดียวกัน จากชิ้นที่คลิกล่าสุด ถึงชิ้นนี้ |
| ดับเบิลคลิก | ชิ้นส่วนก่อสร้าง: ทั้งสิ่งก่อสร้าง ส่วนหนึ่งของเรือ หรือกลุ่มที่เชื่อมกันอื่นๆ: ทั้งกลุ่ม วัตถุอื่นใด (หีบ ป้าย ต้นไม้): วัตถุนั้น พร้อมเปิดตัวตรวจดูข้อมูล ในเครื่องมือ มุมมอง การดับเบิลคลิกวัตถุ จะสลับไปที่ เลือก |
| ลากบนพื้นว่าง | เลือกสิ่งที่อยู่ในกล่อง (หรือในเส้นรอบบนพื้น เมื่อตั้ง **การลากจะวาด** ไว้แบบนั้น) `Ctrl`: เพิ่มในการเลือก `Shift`: เอาออก |
| `Alt` + ลาก | เหมือนกัน แต่เริ่มบนวัตถุได้ด้วย (ไม่โดนวัตถุ) |
| `Ctrl+A` / `Alt+A` | เลือกวัตถุที่แสดงอยู่ทุกชิ้น / ล้างการเลือก |
| `Ctrl+I` | กลับการเลือก |
| `Ctrl+H` / `Alt+H` | ซ่อนวัตถุที่เลือกในมุมมอง / แสดงอีกครั้ง |
| `Alt+Z` | เปิดหรือปิด **เลือกทะลุ**: กล่องจะเลือกสิ่งที่ถูกบัง อยู่หลังวัตถุอื่นด้วย |
| `Shift+F` หรือ `.` บนแป้นตัวเลข | จัดมุมกล้องให้เห็นส่วนที่เลือก |

## แยกตามเครื่องมือ

### แปรงปั้นและระบาย

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| ลากปุ่มซ้าย | ใช้แปรงบนพื้น |
| `Alt`+คลิก | ใช้ความสูงของพื้นตรงนั้น เป็นความสูงของ ปรับราบ แล้วสลับไปที่ **ปรับราบ** |
| `Alt+Shift`+คลิก | ตั้งช่วงความสูงของ [มาสก์](../masks.md) ให้สูงและต่ำกว่าจุดนั้น 2 m (ใช้กับเครื่องมือ เส้นทาง ได้ด้วย) |

### ขอบเขต

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| ลาก (กล่อง) | วาดกล่อง |
| คลิก (รูปหลายเหลี่ยม) | เพิ่มจุด ดับเบิลคลิก: ปิดรูปหลายเหลี่ยม |
| `Enter` | ปิดรูปหลายเหลี่ยม ที่กำลังวาด เมื่อเลือกเสร็จแล้ว จะทำการกระทำที่เลือกไว้ |
| `Enter` แล้ว `Del` | เมื่อเลือก **วัตถุ** ไว้: เลือกวัตถุข้างใน แล้วลบในเครื่องมือ เลือก |
| `Backspace` | ลบจุดสุดท้ายของรูปหลายเหลี่ยม |
| `Esc` | ล้างส่วนที่เลือก (กล่องหรือรูปหลายเหลี่ยม) |

### เส้นทาง

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| คลิก | เพิ่มจุด |
| ลากเส้น | เพิ่มจุดตรงนั้น แล้วย้ายจุด |
| ลากจุด | ย้ายจุด |
| `Ctrl`+คลิกจุด | ลบจุด |
| `Alt`+คลิก | ใช้ความสูงของพื้นตรงนั้น เป็นความสูงของเส้นทาง (ทางลาด: จุดเริ่มต้น) |
| `Ctrl+Alt`+คลิก | ทางลาด: ใช้ความสูงเป็นจุดสิ้นสุด |
| `Alt+Shift`+คลิก | ตั้งช่วงความสูงของ [มาสก์](../masks.md) เหมือนกับแปรง |
| `Enter` | ใช้เส้นทาง |
| `Backspace` | ลบจุดสุดท้าย |
| `Esc` | ล้างเส้น |

### จัดวาง

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| ลากปุ่มซ้าย (แปรง) | วางวัตถุใต้แปรง `Shift` + ลาก: นำออก |
| คลิก (เส้น รูปหลายเหลี่ยม) | เพิ่มจุด ลากเส้นรอบ: เพิ่มจุดตรงนั้น ลากจุด: ย้ายจุด `Ctrl`+คลิกจุด: ลบจุด |
| ดับเบิลคลิกจุดสุดท้าย | วางไปตามรูปทรง |
| ลาก (กริด รูปทรงแบบเส้น) | วาดกล่องของกริด หรือวาดรูปทรง จากปลายหนึ่งไปอีกปลายหนึ่ง |
| `Alt`+คลิก | ใช้ความสูงตรงนั้น เป็น **ระดับความสูง** |
| `Enter` | วางไปตามเส้น วงกลม หรือสี่เหลี่ยม หรือในกริด หรือรูปหลายเหลี่ยม |
| `Backspace` | ลบจุดสุดท้าย ของเส้นหรือรูปหลายเหลี่ยม |
| `Esc` | ล้างรูปทรงที่กำลังวาด หรือยกเลิก **เลือกจากโลก** |
| `N` | เลย์เอาต์แบบสุ่มใหม่ |
| `R` | หมุนภาพตัวอย่าง กริดที่วาดไว้ หรือรูปหลายเหลี่ยม หนึ่งในสี่รอบ |
| `,` / `.` หรือ `Alt` + ล้อเมาส์ | หมุนภาพตัวอย่าง กริดที่วาดไว้ หรือรูปหลายเหลี่ยม ทีละ 15° (`Shift` ละเอียดขึ้น: 1°) |
| `PgUp` / `PgDn` หรือ `Ctrl` + ล้อเมาส์ | ยกหรือลดสิ่งที่วาง ทีละ 0.5 m (`Shift` ละเอียดขึ้น: 0.1 m) |
| คลิกวัตถุ (**เลือกจากโลก**) | ใช้ชนิดของวัตถุนั้น `Shift`+คลิก เพิ่มเข้าในชนิดที่เลือก |

### ก่อสร้าง วาง และการย้ายส่วนที่เลือก: ระยะของแถบก่อสร้าง

[ก่อสร้าง](../build.md) การวาง และ เลือก หมุนและยกด้วยปุ่มเดียวกัน ตามระยะที่ตั้งไว้บน
[แถบก่อสร้าง](../build.md#แถบกอสราง) (**หมุนทีละ** เริ่มต้นที่ 22.5° **ยก** เริ่มต้นที่ 0.5 m) `Shift`
ทำให้ระยะละเอียดขึ้นเสมอ

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| `,` / `.` หรือ `Alt` + ล้อเมาส์ | หมุนชิ้นส่วน สิ่งที่วาง หรือส่วนที่เลือก ตามระยะ **หมุนทีละ** (`Shift`: 1°) |
| `PgUp` / `PgDn` หรือ `Ctrl` + ล้อเมาส์ | ยกหรือลด ตามระยะ **ยก** (`Shift`: หนึ่งในห้าของระยะ) |

### ก่อสร้าง (ในโลก เวิร์กช็อป และการก่อสร้างในดันเจี้ยน)

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| คลิก | วางชิ้นส่วน (**วางเรียง**: **ชิ้นเดียว**) หรือเพิ่มจุด (**เส้น**) |
| ลาก | ชิ้นส่วนเรียงเป็นแถว (**ชิ้นเดียว**) วงกลม สี่เหลี่ยม หรือกริด (**วางเรียง**) |
| กด `Alt` ค้าง | วางชิ้นส่วนทีละหนึ่งในสี่เมตร โดยไม่สแนป |
| `R` | หมุนชิ้นส่วนหนึ่งในสี่รอบ |
| `Q` / `E` | เมื่อตั้ง **สแนป** เป็น **กำหนดเอง**: จุดสแนปก่อนหน้า / ถัดไปของชิ้นส่วน |
| `Shift` + คลิกขวา | นำชิ้นส่วนใต้ตัวชี้ออก |
| คลิกปุ่มกลาง | ก่อสร้างด้วยชนิด ของชิ้นส่วนใต้ตัวชี้ |
| `Enter` | วางเส้น วงกลม สี่เหลี่ยม หรือกริด |
| `Backspace` | ลบจุดสุดท้ายของเส้น |
| `Esc` | ล้างเส้น รูป หรือกริด ที่กำลังวาด |

### วาง

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| คลิก | วางสิ่งที่จะวาง คลิกอีกครั้ง เพื่อวางสำเนาเพิ่ม |
| `R` | หมุนหนึ่งในสี่รอบ |
| `X` | สะท้อน |
| `Esc` | หยุดวาง กลับไปที่เครื่องมือ ขอบเขต |

### ย้ายส่วนที่เลือก (เลือก)

| ปุ่มหรือเมาส์ | การกระทำ |
|---|---|
| ลากวัตถุที่เลือก | ย้ายส่วนที่เลือก |
| ลากลูกศรหรือวงแหวน | ย้ายตามแกนนั้น หรือหมุน |
| `R` | หมุนส่วนที่เลือก หนึ่งในสี่รอบ |
| `End` | วางลงบนพื้น |
| `Del` | ลบวัตถุที่เลือก |
| `I` | เปิดตัวตรวจดูข้อมูล ของวัตถุที่เลือก (เลือกวัตถุชิ้นเดียว) |
| `Esc` | ยกเลิกการย้าย ที่กำลังทำ หรือกล่อง หรือเส้นรอบ ที่กำลังวาด |

### เครื่องมืออื่นๆ

| เครื่องมือ | ปุ่มหรือเมาส์ | การกระทำ |
|---|---|---|
| ภูมิประเทศ | คลิก | ใส่ภูมิประเทศตรงนั้น: รูปทรงของสูตร ภูเขา หรือรูปภาพ |
| วัด | คลิกสองจุด | วัดระหว่างสองจุด `Esc` ล้างการวัด |
| ดันเจี้ยน | `R` | หมุนห้องที่จะเพิ่ม: ห้องจะต่อด้วยช่องเปิดถัดไป |
| | `Del` | ลบห้องที่เลือก |
| สคริปต์ | `Ctrl+Enter` | รันสคริปต์ (ในช่องโค้ด) |
| ตัวตรวจดูข้อมูล | `Esc` | ปิด |
| เครื่องมือของม็อด | ปุ่มของตัวเอง | เครื่องมือใต้ **ม็อด** บนแถบเครื่องมือ จะรับปุ่มที่ใช้ก่อน ปุ่มอื่นทำงานตามปกติ |

## Esc ทำงานอย่างไร

`Esc` ทำสิ่งแรกในรายการนี้ ที่ใช้ได้ แล้วหยุด:

1. ยกเลิกการเลือกชนิด ด้วย **เลือกจากโลก**
2. หยุดวาง (กลับไปที่เครื่องมือ ขอบเขต)
3. ปิดตัวตรวจดูข้อมูล
4. ยกเลิกสิ่งที่เครื่องมือกำลังทำ: การย้ายใน เลือก กล่องหรือเส้นรอบที่กำลังวาด รูปทรงของ จัดวาง หรือเส้นที่วางเรียงด้วย
   ก่อสร้าง กล่องหรือรูปหลายเหลี่ยมของ ขอบเขต จุดของ เส้นทาง การวัด
5. สลับไปที่เครื่องมือ มุมมอง

## แผนที่โลก และโลกใหม่

| เมาส์ | การกระทำ |
|---|---|
| ลาก | เลื่อนแผนที่ |
| ล้อเมาส์ | ซูมเข้าหาเมาส์ |
| คลิก | เลือกจุด (โซนสำหรับ **แก้ไขใน 3D**) |
| ดับเบิลคลิก (แผนที่ของโลกใหม่) | แสดงทั้งโลก |
| `Enter` ในช่องค้นหา | ค้นหา |

## หน้าต่างวิธีใช้

| ปุ่ม | การกระทำ |
|---|---|
| `F1` | เปิดวิธีใช้ ที่สิ่งที่คุณใช้อยู่: เครื่องมือ ตัวตรวจดูข้อมูล แผนที่ หน้าเริ่มต้น… (หน้าใดก็ได้) |
| `Ctrl+F` | ค้นหาในวิธีใช้ |
| `Alt+Left` / `Alt+Right` | ย้อนกลับ / ไปข้างหน้า |
| `Esc` | ปิดรูปภาพที่ขยายอยู่ หากไม่มี จะล้างการค้นหา |
| `Enter` ในช่องค้นหา | เปิดหน้าแรกที่พบ |
