# การแก้ไขแบบไลฟ์

ในโหมดไลฟ์ เอดิเตอร์ทำงานกับโลกของเกม ที่ **กำลังรัน** แทนไฟล์ ผู้เล่นยังเชื่อมต่ออยู่ได้: ผู้เล่นเห็นการเปลี่ยนแปลงของคุณ ทันทีที่คุณนำไปใช้ และคุณเห็นสิ่งที่ผู้เล่นสร้าง ขณะที่คุณแก้ไข หน้านี้อธิบายว่า เอดิเตอร์เข้าถึงเกมอย่างไร อะไรถูกส่งระหว่างกัน และเกิดอะไรขึ้น เมื่อผู้เล่นและเอดิเตอร์ เปลี่ยนที่เดียวกัน

## การเชื่อมต่อทำงานอย่างไร

โหมดไลฟ์ต้องใช้ปลั๊กอินเล็กๆ ชื่อ **WorldEditorBridge** ในเกมที่ **เป็นโฮสต์** ของโลก: เซิร์ฟเวอร์เฉพาะ หรือเกมของคุณเอง เมื่อคุณเล่นคนเดียว หรือเป็นโฮสต์ ปลั๊กอินรันบน **BepInEx** ตัวโหลดม็อดที่ใช้กันทั่วไปของ Valheim ผู้เล่นที่เข้าร่วม ไม่ต้องมีทั้งสองอย่าง รวมผู้เล่นบนคอนโซลด้วย และการแก้ไขแบบออฟไลน์ ก็ไม่ต้องมีเช่นกัน

ปลั๊กอินตอบเอดิเตอร์ ผ่านพอร์ตหนึ่ง ของคอมพิวเตอร์ที่ปลั๊กอินรันอยู่ (ตอนแรกคือ 5182) และสร้างมาให้เป็นส่วนตัว:

- **รับฟังเฉพาะ บนคอมพิวเตอร์เครื่องนั้นเอง** (`127.0.0.1`) จึงไม่มีอะไรในเครือข่าย เข้าถึงได้ การตั้งค่า `BindAddress` เปิดให้เครือข่ายในพื้นที่ และ VPN ของคอมพิวเตอร์ เข้าถึงได้ (ไม่เคยเปิดสู่อินเทอร์เน็ต: ผู้เรียกจากที่นั่น จะถูกปฏิเสธ) โดยโทเค็นไม่ถูกเข้ารหัส ให้คงไว้ตามเดิม เว้นแต่คุณจะแก้ไข จากคอมพิวเตอร์อีกเครื่องในบ้าน ([ไม่ใช้ SSH](../live-mode.md#ไมใช-ssh))
- **ต้องใช้โทเค็นลับ** เมื่อเริ่มทำงานครั้งแรก ปลั๊กอินจะเขียน `BepInEx/config/Tie.WorldEditorBridge.cfg` พร้อม **โทเค็น** ที่เป็นตัวอักษรและตัวเลขสุ่ม 24 ตัว คำขอที่ไม่มีโทเค็น จะถูกปฏิเสธ จนกว่าเกมหรือเซิร์ฟเวอร์ จะเริ่มทำงานพร้อมปลั๊กอินสักครั้ง จะยังไม่มีโทเค็น

**เกมของคุณเอง** เอดิเตอร์รัน บนคอมพิวเตอร์เครื่องเดียวกัน จึงอ่านพอร์ตและโทเค็น จากไฟล์นั้นเอง ในทุกโฟลเดอร์ BepInEx ที่รู้จัก (โฟลเดอร์ Valheim ของคุณ โปรไฟล์ตัวจัดการม็อดของคุณ โฟลเดอร์ที่เพิ่มใน **การตั้งค่า**) และถามปลั๊กอินแต่ละตัวที่พบ ว่ามีโลกโหลดอยู่หรือไม่

**เซิร์ฟเวอร์เฉพาะ** คอมพิวเตอร์ของคุณ เข้าถึงปลั๊กอินโดยตรงไม่ได้ เอดิเตอร์จึงสร้าง ทางเข้าของตัวเอง:

```text
 your computer                                   the server
 ┌──────────────────────┐   SSH, encrypted   ┌─────────────────────────────────────┐
 │ editor ── port 15182 ═╪═══════════════════╪═► 127.0.0.1:5182  WorldEditorBridge │
 └──────────────────────┘                    │                   inside Valheim    │
                                             └─────────────────────────────────────┘
```

1. เอดิเตอร์ล็อกอินเข้าเซิร์ฟเวอร์ ผ่าน **SSH** ด้วยบัญชีของคุณ (เอดิเตอร์มี SSH ของตัวเอง จึงไม่ต้องใช้โปรแกรม `ssh`)
2. เอดิเตอร์ส่งต่อพอร์ตว่าง ของคอมพิวเตอร์ของคุณ (ตั้งแต่ 15182 ขึ้นไป) ผ่านการเชื่อมต่อเข้ารหัสนั้น ไปยังพอร์ตของปลั๊กอิน บนเซิร์ฟเวอร์: นี่คือ **ทันเนล SSH**
3. เอดิเตอร์ส่งโทเค็น ซึ่ง **คุณ** เป็นคนพิมพ์: เอดิเตอร์ไม่เคยอ่านโทเค็น จากเซิร์ฟเวอร์ ดังนั้นการล็อกอิน SSH อย่างเดียว ไม่พอที่จะเปลี่ยนโลก ผู้ที่เชื่อมต่อ ต้องรู้ความลับของปลั๊กอินด้วย

เซิร์ฟเวอร์ที่แผงควบคุมเกม (Pterodactyl, Pelican) รันในคอนเทนเนอร์ Docker มี `127.0.0.1` ของตัวเอง ซึ่งทันเนลไปยังเครื่อง เข้าไม่ถึง และเซิร์ฟเวอร์เกม ที่เช่าจากผู้ให้บริการ มักไม่ให้ล็อกอิน SSH เลย: ดู [แก้ไขเซิร์ฟเวอร์ที่เช่า หรือโฮสต์ผ่านแผงควบคุม](../guides/edit-a-rented-server.md)

เอดิเตอร์ยังจำ ตัวตนของเซิร์ฟเวอร์ ไว้ตั้งแต่การเชื่อมต่อครั้งแรก ถ้าตัวตนเปลี่ยนไปเมื่อใด เอดิเตอร์จะปฏิเสธการเชื่อมต่อ เพราะอาจมีคน แอบอ้างเป็นเซิร์ฟเวอร์ของคุณ

ปลั๊กอินเปลี่ยนเฉพาะโลก ที่เกมของปลั๊กอินเป็นโฮสต์ ในเกมที่เข้าร่วม เซิร์ฟเวอร์ของคนอื่น ปลั๊กอินจะปฏิเสธ เพราะเกมแบบนั้น รู้จักเฉพาะวัตถุ รอบผู้เล่นของตัวเอง ใช้ปลั๊กอินจากรุ่นเดียวกัน กับเอดิเตอร์ของคุณ

## ส่งอะไร และเมื่อไร

**เมื่อคุณเชื่อมต่อ** เอดิเตอร์อ่านทั้งโลกจากเกม: วัตถุทุกชิ้น โซนที่เกมสร้างแล้ว สถานที่ เป็นข้อมูลเดียวกับที่เซฟเก็บไว้ ดังนั้นแผนที่ การค้นหา และเครื่องมือทุกอัน ทำงานเหมือนตอนออฟไลน์ ในโลกขนาดใหญ่ ใช้เวลาสักพัก ถึงไม่กี่นาที เอดิเตอร์ยังขอข้อมูลวัตถุ ที่เกมรู้จัก ซึ่งไม่ใช่ของ Valheim เอง (ชิ้นส่วนของม็อด) เพื่อให้มีชื่อ และแสดงในรายการ จัดวาง และแผง ก่อสร้าง

**เมื่อคุณนำไปใช้** (**นำไปใช้แบบไลฟ์** หรือแต่ละขั้นตอนทันที ด้วย **อัตโนมัติ**) เอดิเตอร์ส่งสิ่งที่เปลี่ยน ตั้งแต่การนำไปใช้ครั้งล่าสุด ตามลำดับนี้:

1. **พื้นดิน** ของทุกโซน ที่คุณเปลี่ยน รวมพื้นดิน ไม่จำกัด (ดู [ไม่จำกัด](ground-limits.md#ไมจำกด))
2. **วัตถุ** ที่คุณลบ จัดวาง วาง แทนที่ เปลี่ยน หรือย้าย
3. **การรีเซ็ตโซน** เป็นลำดับสุดท้าย เกมสร้างโซนเหล่านั้นใหม่ เอดิเตอร์จึงอ่านโลกใหม่ ประวัติตามมาด้วย โดยไม่มีสิ่งที่ทำ ในโซนเหล่านั้น

เกมแบ่งปัน การเปลี่ยนแปลงแต่ละรายการ ให้ผู้เล่นทุกคนที่เชื่อมต่อ แบบเดียวกับสิ่งที่ผู้เล่นสร้าง และบันทึกไปพร้อมกับโลก วัตถุที่วางแบบไลฟ์ ถูกสร้างโดยเซิร์ฟเวอร์ ผู้เล่นจึงเห็นเหมือนสิ่งที่เพิ่งสร้าง หรือเพิ่งปลูก

ปลั๊กอินทำทั้งหมดนี้ ในลูปของเกมเอง ไม่กี่คำขอต่อเฟรม เพื่อให้เกมไม่อ่าน หรือเปลี่ยนโลก จากสองที่พร้อมกัน การเปลี่ยนแปลงใหญ่ (วัตถุหลายพันชิ้น) อาจทำให้เซิร์ฟเวอร์ สะดุดชั่วครู่ ถ้าเกมไม่รับคำขอ ภายใน 30 วินาที ปลั๊กอินจะทิ้งคำขอนั้น: ไม่มีอะไรถูกทำ และไม่มีอะไรถูกทำเครื่องหมาย ว่านำไปใช้แล้ว จึงต้องนำไปใช้อีกครั้ง ถ้าคำตอบหายไป ระหว่างทางกลับแทน (ทันเนลหลุด) เอดิเตอร์จะไม่รู้ว่า ทำไปแล้วหรือยัง การส่งอีกครั้งปลอดภัย เพราะปลั๊กอินจำคำขอ ที่ทำไปแล้วได้ และไม่สร้างวัตถุซ้ำ นำไปใช้ได้ทีละครั้ง

### การย้ายวัตถุ ยังคงเป็นวัตถุเดิม

วัตถุที่คุณย้าย หรือหมุน จะย้ายในเกม ด้วย ID ของตัวเอง เมื่อไม่มีอย่างอื่นของวัตถุนั้นเปลี่ยน ม็อดที่ติดตามวัตถุ ขณะที่เกมรันอยู่ (ป้ายชื่อของหีบ หีบของคลังสินค้า Ward) ก็ยังรู้จักวัตถุนั้น และหีบเก็บของข้างใน แบบที่เกมมี วัตถุที่คุณเปลี่ยนข้อมูล ก็เก็บ ID ไว้แบบเดียวกัน

มีข้อแม้อยู่ เกมของผู้เล่น วางวัตถุที่ตั้งอยู่กับที่ (ผนัง หีบ) ลงครั้งเดียว เมื่อวัตถุเข้ามาในระยะ และไม่ย้ายอีกหลังจากนั้น ดังนั้นการย้าย จะเก็บ ID ไว้ได้ ก็ต่อเมื่อไม่มีผู้เล่นคนใด โหลดทั้งตำแหน่งเก่า และตำแหน่งใหม่อยู่ (ประมาณ 160 m รอบผู้เล่นแต่ละคน) ไม่เช่นนั้น วัตถุจะถูกสร้างใหม่ ที่ตำแหน่งใหม่ และนำออกจากตำแหน่งเก่า และข้อความการนำไปใช้ บอกจำนวน: สำหรับม็อดอื่น นั่นคือวัตถุใหม่ ย้ายสิ่งก่อสร้าง ขณะที่ไม่มีใครอยู่ใกล้ เพื่อเก็บทุกอย่างของสิ่งก่อสร้างไว้ กลุ่มที่เชื่อมกันของม็อด (เรือและชิ้นส่วน) และสิ่งมีชีวิต ถูกสร้างใหม่เสมอ

## การติดตามเกม

ขณะที่พื้นที่เปิดอยู่ เอดิเตอร์ถามเกมทุก 2 วินาที ว่ามีอะไรเปลี่ยน ในโซนของพื้นที่นั้น วิธีนี้ใช้ทรัพยากรน้อย: เกมตอบด้วยตัวเลขหนึ่งตัวต่อโซน ซึ่งเปลี่ยน ทุกครั้งที่มีบางอย่างในโซนเปลี่ยน และอ่านใหม่ เฉพาะโซนที่ตัวเลขเปลี่ยน แถบสถานะบอกสิ่งที่เข้ามา ("จากเกม: วัตถุใหม่ 2 ชิ้น, นำออก 1 ชิ้น, พื้นดินของ 1 โซน") การเปลี่ยนเฉพาะข้อมูล เช่น ไฟที่มอดลง จะเข้ามาโดยไม่มีข้อความ

- **วัตถุ** ที่ผู้เล่นสร้าง นำออก หรือเปลี่ยน จะปรากฏ หายไป หรือเปลี่ยนในเอดิเตอร์ โดยไม่มีขั้นตอนใน ประวัติ วัตถุที่เปลี่ยน ยังเป็นวัตถุเดิมในเอดิเตอร์ ดังนั้นส่วนที่เลือก ตัวตรวจดูข้อมูล และตำแหน่งใน ประวัติ ยังอยู่กับวัตถุนั้น
- **วัตถุของคุณเอง เมื่อนำไปใช้แล้ว** จะแสดงแบบที่เกมมีจริง: ตรงที่ฟิสิกส์ทำให้ชิ้นส่วนลงตัว พลังชีวิต และจุดเกิด ที่เกมให้สิ่งมีชีวิต
- **สิ่งที่เคลื่อนที่ หรือเปลี่ยนเอง** (สิ่งมีชีวิต เรือ รถลาก ไอเทมที่ตกอยู่ ไฟ และเตาหลอม) จะถูกติดตาม ขณะที่เคลื่อนที่ โดยไม่ต้องอ่านทั้งโซน ทุกครั้ง
- **พื้นดิน** ที่ขุด ปรับระดับ หรือระบายในเกม จะเข้ามา ตรงที่คุณไม่มีการเปลี่ยนแปลง ของตัวเองในโซนนั้น (ดูด้านล่าง เมื่อคุณมี)

การติดตาม เกิดขึ้นเฉพาะในเอดิเตอร์ 3D ไม่เกิดขณะลากแปรง หรือขณะนำไปใช้ แผนที่แสดงโลก แบบที่อ่านครั้งล่าสุด: **โหลดใหม่** อ่านทั้งหมดใหม่

## เอดิเตอร์และผู้เล่นหลายคน

ผู้เล่นและเอดิเตอร์ เปลี่ยนที่เดียวกันได้ เอดิเตอร์จัดการแบบนี้:

| สิ่งที่เกิดขึ้น | สิ่งที่เอดิเตอร์ทำ |
|---|---|
| ผู้เล่นเปลี่ยนพื้นดิน ของโซนที่คุณมีการเปลี่ยนแปลง ที่ยังไม่ได้นำไปใช้ | ของคุณถูกเก็บไว้ และแถบสถานะบอกไว้ **นำไปใช้แบบไลฟ์** จะถามก่อน (**นำไปใช้ทับ การเปลี่ยนแปลงของเกม**): การนำไปใช้ จะเขียนพื้นดินของคุณ ทับโซนนั้น และสิ่งที่ผู้เล่นทำ ในระหว่างนั้น อาจหายไป **ไม่ใช่ตอนนี้** เก็บการเปลี่ยนแปลงของคุณ ไว้ในสถานะรอดำเนินการ |
| ผู้เล่นเก็บ หรือทำลายวัตถุ | วัตถุหายไปถาวร: การเลิกทำและทำซ้ำ จะไม่แตะวัตถุนั้น และการลบวัตถุนั้น ที่คุณยังไม่ได้นำไปใช้ จะถูกทิ้ง รวมถึงวัตถุที่คุณวางเองด้วย |
| คุณลบวัตถุ และนำไปใช้ | วัตถุยังถูกลบอยู่ การเลิกทำ นำกลับมาเป็นสำเนา (ดู [การนำไปใช้แบบไลฟ์](saving-and-history.md#การนำไปใชแบบไลฟ)) |
| คุณย้ายสิ่งก่อสร้าง ขณะที่ผู้เล่นอยู่ใกล้ | ถูกสร้างใหม่ แทนการย้าย (ดู [การย้ายวัตถุ ยังคงเป็นวัตถุเดิม](#การยายวตถ-ยงคงเปนวตถเดม)) |
| คุณเปลี่ยนวัตถุ ในตัวตรวจดูข้อมูล ขณะที่เกมก็เปลี่ยนวัตถุนั้นด้วย | ตัวตรวจดูข้อมูล ไม่นำไปใช้ทับเวอร์ชันที่ใหม่กว่า: แต่แสดงเวอร์ชันนั้น ให้เปลี่ยนอีกครั้ง |
| คุณรีเซ็ตโซน ที่มีผู้เล่นยืนอยู่ใกล้ | เกมสร้างโซนใหม่ทันที ไม่เช่นนั้น ครั้งถัดไปที่มีคนมา |

ปลั๊กอินตอบเอดิเตอร์ใดก็ได้ ที่มีโทเค็น และไม่แยกการเปลี่ยนแปลง ของเอดิเตอร์ตัวหนึ่ง ออกจากของผู้เล่น: สิ่งที่เอดิเตอร์อีกตัว นำไปใช้ จะมาถึงของคุณ แบบเดียวกับ การเปลี่ยนแปลงของผู้เล่น

**อัตโนมัติ และ Claude** เมื่อเปิด **อัตโนมัติ** ทุกขั้นตอน จะไปถึงผู้เล่น ทันทีที่คุณทำเสร็จ การลากแปรงยาวๆ จะเป็นการนำไปใช้ครั้งเดียว ด้วยเหตุนี้ Claude จะไม่เปลี่ยนอะไร ในโลกไลฟ์ ขณะที่เปิด อัตโนมัติ (ดู [สคริปต์และ Claude](safety.md#สครปตและ-claude))
