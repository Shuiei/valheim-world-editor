# ความปลอดภัยและความเป็นส่วนตัว

เอดิเตอร์เป็นโปรแกรม บนคอมพิวเตอร์ของคุณ เขียนลงโลกของคุณ เฉพาะเมื่อคุณกด **บันทึกลงโลก** ไม่ส่งอะไรไปที่ไหน เว้นแต่คุณจะเชื่อมต่อ กับเซิร์ฟเวอร์ หรือกับ Claude และไม่เก็บข้อมูลลับไว้ในล็อก หน้านี้บอกว่า เอดิเตอร์เขียนอะไร อะไรออกจาก คอมพิวเตอร์ของคุณได้ และอะไรรันด้วยสิทธิ์ของคุณ

## สิ่งที่เอดิเตอร์เขียน

**โลกของคุณ** เฉพาะเมื่อคุณบันทึก ก่อนหน้านั้น ทุกการเปลี่ยนแปลง อยู่ในสถานะรอดำเนินการ และอยู่ในหน่วยความจำ ของเอดิเตอร์ (ดู [การเปลี่ยนแปลงที่รอดำเนินการ](saving-and-history.md#การเปลยนแปลงทรอดำเนนการ)) การบันทึก จะเพิ่มเซฟใหม่ที่มีหมายเลข ลงในโฟลเดอร์ของโลก และไม่ลบของเก่า จนกว่าจะอ่านเซฟใหม่ กลับได้ถูกต้อง (ดู [การบันทึกโลก](saving-and-history.md#การบนทกโลก)) โลกใหม่ จะอยู่ในโฟลเดอร์ใหม่ ไม่เขียนทับโลกที่มีชื่อเดียวกัน ปิดเกมก่อน: เกมที่กำลังรัน จะเขียนทับไฟล์ ที่เอดิเตอร์บันทึกไว้

**เกมไลฟ์** เฉพาะเมื่อคุณนำไปใช้ แล้วเกมจะบันทึก การเปลี่ยนแปลงเอง แบบที่บันทึกสิ่งที่ผู้เล่นสร้าง

**พิมพ์เขียวของคุณ**: ไฟล์ `.blueprint` และรูปภาพ `.png` ในโฟลเดอร์ของ Homestead ซึ่งอยู่ในโฟลเดอร์เซฟของ Valheim เมื่อคุณบันทึกพิมพ์เขียว **ลบ** จะลบทั้งสองไฟล์ หลังจากถาม

**โฟลเดอร์ข้อมูลของตัวเอง**: `~/.local/share/ValheimWorldEditor` บน Linux `%LOCALAPPDATA%\ValheimWorldEditor` บน Windows `~/Library/Application Support/ValheimWorldEditor` บน macOS (ด้านล่างของเมนูหน้าเริ่มต้น แสดงไว้) โฟลเดอร์นี้เก็บ:

| อะไร | ไฟล์ |
|---|---|
| การตั้งค่า และตัวเลือกของคุณ | `settings.json`, `prefs.json`, `place.json` (พรีเซ็ตของ จัดวาง รายการโปรด ชนิดที่ใช้ล่าสุด), `stamps.json`, `selections.json` |
| เซิร์ฟเวอร์ที่บันทึกไว้ | `servers.cfg`: ที่อยู่ ผู้ใช้ โทเค็น ตัวตนของเซิร์ฟเวอร์ และรหัสผ่าน เมื่อคุณติ๊ก **จำรหัสผ่าน** (ดูด้านล่าง) |
| ประวัติ | `history/` หนึ่งไฟล์ต่อหนึ่งโลก (ดู [ประวัติ](saving-and-history.md#ประวต)) |
| งานของคุณ | `scripts/` (สคริปต์ที่บันทึกไว้), `heightmaps/` (แผนที่ความสูงที่ส่งออก), `blueprints/export` (ไฟล์ `.vbuild`) |
| สิ่งที่เรียนรู้จากเกมของคุณ | `game-index.json` และไฟล์ `game-*.json` อื่นๆ (ตำแหน่งของสิ่งต่างๆ ในไฟล์ของ Valheim), `mod-catalogue.json` (วัตถุของม็อด ที่เห็นในเกมไลฟ์), `mod-bundles/` (โมเดลของม็อด ที่คัดลอกออกมาจาก DLL) |
| ล็อก | `ValheimWorldEditor.log` สร้างใหม่ทุกครั้งที่เปิด `perf-native.log` เฉพาะขณะที่ **บันทึกอัตราเฟรม** เปิดอยู่ |

**สิ่งที่ไม่เคยเปลี่ยน** เอดิเตอร์อ่านโฟลเดอร์เกม Valheim โฟลเดอร์ BepInEx และไฟล์ม็อดของคุณ (โมเดล พื้นผิว กฎของเกม การตั้งค่าของปลั๊กอิน) และไม่เขียนอะไรลงไปตรงนั้น เอดิเตอร์อ่านโค้ดของม็อด เพื่อเรียนรู้ชื่อค่าต่างๆ และไม่เคยรันโค้ดนั้น

**รหัสผ่าน** รหัสผ่านที่จำไว้ จะเก็บเป็นข้อความธรรมดา ใน `servers.cfg` บน Linux มีแค่คุณ ที่อ่านไฟล์นี้ได้ ถึงอย่างนั้น ให้ใช้คีย์ SSH เมื่อทำได้ วลีรหัสผ่านของคีย์ ไม่เคยถูกบันทึก **เลิกจำ** ข้างเซิร์ฟเวอร์ที่บันทึกไว้ จะนำเซิร์ฟเวอร์นั้นออก พร้อมรหัสผ่าน และโทเค็น

## ไม่มีอะไรออก จากคอมพิวเตอร์ของคุณ

เอดิเตอร์ไม่มีบัญชี ไม่มีการติดตาม และไม่มีการตรวจหาอัปเดต จะติดต่อภายนอก เฉพาะในกรณีด้านล่าง ซึ่งแต่ละกรณี เป็นตัวเลือกของคุณ:

| เมื่อใด | อะไรไปที่ไหน |
|---|---|
| คุณเชื่อมต่อกับ **เซิร์ฟเวอร์เฉพาะ** | การเชื่อมต่อ SSH ที่เข้ารหัส ไปยังเซิร์ฟเวอร์นั้นเท่านั้น ด้วยบัญชีที่คุณให้ ปลั๊กอินถูกเข้าถึง ผ่านการเชื่อมต่อนี้ ไม่เคยผ่านอินเทอร์เน็ตแบบเปิด (ดู [การเชื่อมต่อทำงานอย่างไร](live-editing.md#การเชอมตอทำงานอยางไร)) |
| คุณแก้ไข **เกมของคุณเอง** แบบไลฟ์ | ไม่มีอะไรออกจากคอมพิวเตอร์: เอดิเตอร์คุยกับปลั๊กอิน บน `127.0.0.1` |
| คุณเชื่อมต่อ **Claude** | แอปของ Claude บนคอมพิวเตอร์ของคุณ คุยกับเอดิเตอร์ บน `127.0.0.1` สิ่งที่เอดิเตอร์ตอบ (ข้อมูลของพื้นที่ รูปภาพของมุมมอง 3D) จะไปถึง Claude เหมือนสิ่งใดก็ตาม ที่คุณให้ Claude |
| คุณคลิกลิงก์ | **รับ Homestead** หรือหน้าวิธีใช้ ที่เปิดบน GitHub จะเปิดในเว็บเบราว์เซอร์ของคุณ |

**ปลั๊กอินเป็นส่วนตัว** WorldEditorBridge รับฟังเฉพาะ บนคอมพิวเตอร์ที่ตัวเองรันอยู่ และตอบเฉพาะคำขอ ที่มีโทเค็นลับ สำหรับเซิร์ฟเวอร์ คุณพิมพ์โทเค็นเอง เอดิเตอร์ไม่เคยอ่านโทเค็น จากเซิร์ฟเวอร์ ดังนั้นการล็อกอิน SSH อย่างเดียว เปลี่ยนโลกไม่ได้ เก็บโทเค็นเป็นความลับ: ใครก็ตาม ที่มีโทเค็น และเข้าถึงพอร์ตได้ จะเปลี่ยนโลกได้ ลบค่าในบรรทัด `Token` ของ `Tie.WorldEditorBridge.cfg` แล้วเริ่มเกมใหม่ เพื่อรับโทเค็นใหม่

**ตัวตนของเซิร์ฟเวอร์ ถูกตรวจสอบ** เอดิเตอร์จำตัวตนของเซิร์ฟเวอร์ ไว้ตั้งแต่การเชื่อมต่อครั้งแรก ถ้าตัวตนเปลี่ยนไปเมื่อใด เอดิเตอร์จะปฏิเสธการเชื่อมต่อ เพราะอาจมีคน แอบอ้างเป็นเซิร์ฟเวอร์ของคุณ หลังจากคุณติดตั้งเซิร์ฟเวอร์ใหม่ ให้ลบค่าในบรรทัด `HostKey` ของเซิร์ฟเวอร์นั้น ใน `servers.cfg` เพื่อยอมรับตัวตนใหม่

## สคริปต์และ Claude

**สคริปต์คือโปรแกรม** [สคริปต์](../scripting.md) คือโค้ด C# และเอดิเตอร์รันด้วยสิทธิ์ของคุณ เหมือนโปรแกรมใดๆ ที่คุณเปิด สคริปต์รันในโปรเซสแยก เพื่อให้ **หยุด** สั่งจบได้เสมอ แต่โปรเซสนั้นไม่ใช่แซนด์บ็อกซ์: สคริปต์อ่านและเขียนไฟล์ของคุณได้ และทำอย่างอื่นใดก็ได้ ที่บัญชีของคุณทำได้ รันเฉพาะสคริปต์ ที่คุณเขียนเองหรือไว้ใจ แบบเดียวกับที่คุณทำกับม็อด

**Claude ทำงานให้คุณ ภายใต้ข้อจำกัด** เมื่อเปิด **อนุญาตให้ Claude เชื่อมต่อ** ใน การตั้งค่า [Claude](../claude.md) จะใช้เครื่องมือของเอดิเตอร์ได้ เอดิเตอร์คุม Claude ไว้แบบนี้:

- **คอมพิวเตอร์เครื่องนี้เท่านั้น พร้อมโทเค็น** เอดิเตอร์รับฟังบน `127.0.0.1` เท่านั้น ปฏิเสธคำขอ ที่ส่งถึงชื่ออื่น (เพื่อให้หน้าเว็บ เข้าถึงไม่ได้ ผ่านที่อยู่ที่ปลอมขึ้น) และปฏิเสธคำขอใดๆ ที่ไม่มีโทเค็น (อักขระสุ่ม 48 ตัว) **ที่อยู่** อื่นใน การตั้งค่า (`0.0.0.0` หรือที่อยู่หนึ่ง ของคอมพิวเตอร์เครื่องนี้) ให้คอมพิวเตอร์อื่น ในเครือข่ายนั้น เชื่อมต่อได้ ด้วยโทเค็น ซึ่งจะส่งไปแบบไม่เข้ารหัส: เฉพาะคอมพิวเตอร์ ที่มีที่อยู่ในพื้นที่ ในเครือข่ายเดียวกับเครื่องนี้ ไม่เคยจากอินเทอร์เน็ต และไม่เคยรวมสคริปต์ (สคริปต์ยังใช้ได้เฉพาะ Claude ของเครื่องนี้) **โทเค็นใหม่** สร้างโทเค็นอีกอัน ปิดสวิตช์ แล้วจะไม่มีอะไรเชื่อมต่อได้
- **รอดำเนินการเท่านั้น** สิ่งใดที่ Claude เปลี่ยน จะอยู่ในสถานะรอดำเนินการ ครั้งละหนึ่งขั้นตอน ติดป้าย **Claude** ใน ประวัติ Claude ไม่เคยบันทึก นำไปใช้แบบไลฟ์ ทิ้ง โหลดใหม่ เขียน หรือลบไฟล์ของคุณ หรือเชื่อมต่อกับเกมไลฟ์: สิ่งเหล่านั้น ยังเป็นของคุณ Claude ไม่เปิดโลกอื่น ขณะที่โลกของคุณ มีการเปลี่ยนแปลงที่ยังไม่บันทึก
- **ไม่ทำอะไรแบบไลฟ์ เมื่อเปิด อัตโนมัติ** ขณะที่โลกไลฟ์เปิด **อัตโนมัติ** อยู่ การเปลี่ยนแปลงแต่ละรายการ จะไปถึงผู้เล่นทันที Claude จึงไม่เปลี่ยนอะไร และขอให้คุณปิด อัตโนมัติ
- **ไม่รันสคริปต์ โดยไม่ได้รับอนุญาต** สคริปต์ของ Claude จะถูกปฏิเสธ จนกว่าคุณจะเปิด **Claude รันสคริปต์ได้** ใน การตั้งค่า (ปิดไว้ตามค่าเริ่มต้น) แม้เปิดแล้ว สคริปต์แต่ละอัน ที่ Claude เขียน จะแสดงให้คุณดูก่อนรัน ให้รันหรือปฏิเสธ: ข้อความในโลก (ป้าย แท็กที่ผู้เล่นคนอื่นเขียน) อาจชักจูง Claude ให้เขียนสคริปต์ที่เป็นอันตราย เครื่องมืออื่นของ Claude รันโค้ดของเอดิเตอร์เอง และไม่ต้องถาม
- **ย้อนได้ง่าย** **ย้อนการเปลี่ยนแปลงของ Claude** ใน ประวัติ นำทุกขั้นตอน ที่ Claude ทำในพื้นที่ที่เปิดอยู่ออก และเก็บของคุณไว้ (ดู [ประวัติ](saving-and-history.md#ประวต))

## ส่วนขยายและแอดออนของม็อด

ม็อดหนึ่งตัว อาจมาพร้อม **ส่วนขยายของเอดิเตอร์**: โค้ดเล็กๆ ที่เอดิเตอร์โหลด เพื่ออ่านและวาดวัตถุของม็อดนั้น ส่วนขยายรันด้วยสิทธิ์ของคุณ เหมือนสคริปต์ คุณจึงเป็นผู้ตัดสินใจ ส่วนขยายแต่ละตัว **ปิด** อยู่ จนกว่าคุณจะเปิดใน **การตั้งค่า → ส่วนขยายของม็อด** และเฉพาะไฟล์นั้นเท่านั้น: เอดิเตอร์จำลายนิ้วมือของไฟล์ (SHA-256) ไว้ ดังนั้นไฟล์ที่เปลี่ยน เช่น จากการอัปเดตม็อด จะปิดอีกครั้ง จนกว่าคุณจะเปิดใหม่

**แอดออน** ที่คุณดาวน์โหลด และแตกไฟล์ลงในโฟลเดอร์ `addons` ของเอดิเตอร์เอง จะรันตามที่ติดตั้ง เพราะการติดตั้ง เป็นตัวเลือกของคุณอยู่แล้ว **การตั้งค่า → แอดออน** ปิดตัวใดก็ได้

## สิ่งที่ล็อกไม่เก็บ

เอดิเตอร์เขียนสิ่งที่ทำ และทุกข้อผิดพลาด ที่จัดการ ลงใน `ValheimWorldEditor.log` **เปิดล็อก** ที่ด้านล่างของเมนูหน้าเริ่มต้น จะเปิดไฟล์นี้ เพื่อให้คุณแนบไปกับรายงานบั๊กได้ ก่อนเขียนแต่ละบรรทัด ข้อมูลส่วนตัวจะถูกนำออก:

- โฟลเดอร์ home ของคุณ เขียนเป็น `~` และพาธไฟล์อื่นๆ ที่อยู่เว็บ ชื่อแบบ `user@host` ที่อยู่ IP และเซิร์ฟเวอร์ และชื่อบัญชีของคุณ จะถูกแทนด้วยตัวยึดตำแหน่ง เช่น `<path>`
- บัญชี รหัสผ่าน วลีรหัสผ่าน และโทเค็น ของเซิร์ฟเวอร์ที่บันทึกไว้ ไม่เคยถูกเขียนลงล็อก

ปลั๊กอิน WorldEditorBridge เขียนลง `BepInEx/LogOutput.log` ของเกมเอง โดยโฟลเดอร์ home ของเซิร์ฟเวอร์ เขียนเป็น `~` เช่นกัน

ถึงอย่างนั้น อ่านล็อกก่อนโพสต์สู่สาธารณะ และเก็บสำเนาของคุณเอง ของโลกที่คุณให้ความสำคัญ (ดู [สำรองโลกก่อนแก้ไข](../guides/back-up-a-world.md))
