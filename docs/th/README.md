# วิธีใช้ Valheim World Editor

Valheim World Editor เปิดโลก Valheim ทั้งที่บันทึกไว้ และที่กำลังรันอยู่ ในหน้าต่าง 3D ปั้นพื้นดิน ก่อสร้าง
จัดวาง และย้ายสิ่งใดก็ได้ แล้วบันทึกกลับ หรือดูการเปลี่ยนแปลง ในเกมขณะที่คุณทำงาน

**มือใหม่:** [ติดตั้งเอดิเตอร์](start/install.md) แล้วทำตาม [การแก้ไขครั้งแรก](start/first-edit.md): ใช้เวลาสิบนาที
บนสำเนาของโลก ไม่มีอะไรเสียหาย ต้องการหาอะไร: ค้นหาในวิธีใช้ (`Ctrl+F` ในหน้าต่างวิธีใช้) หรือเริ่มจากงาน
ด้านล่าง ในเอดิเตอร์ `F1` หรือ **?** เล็กๆ ที่ด้านบนของแผง จะเปิดวิธีใช้ ของเครื่องมือนั้น

> [!IMPORTANT]
> เก็บสำเนาของโลกไว้ ก่อนเปลี่ยนแปลง: ดู [สำรองโลกก่อนแก้ไข](guides/back-up-a-world.md) เอดิเตอร์ตรวจว่า
> ทุกการบันทึก อ่านกลับได้ถูกต้อง ก่อนจะปล่อยไฟล์เดิมไป แต่ไม่เก็บสำเนาของตัวเองไว้

## เริ่มต้นใช้งาน

- [ติดตั้งเอดิเตอร์](start/install.md): ดาวน์โหลด เปิดครั้งแรกบน Windows, Linux หรือ macOS และปลั๊กอิน
  สำหรับการแก้ไขแบบไลฟ์
- [การแก้ไขครั้งแรกของคุณ](start/first-edit.md): เปิดสำเนาของโลก ยกเนินเขา ปลูกต้นไม้ บันทึก แล้วดูในเกม
- [การก่อสร้างครั้งแรก](start/first-build.md): สร้างกระท่อมในเวิร์กช็อป บันทึกเป็นพิมพ์เขียว แล้ววางลงในโลก

## เครื่องมือ

- [หน้าต่างเอดิเตอร์](editor-basics.md): หน้าเริ่มต้น แถบด้านบน แถบเครื่องมือ กล้อง พื้นที่ การบันทึก
  ประวัติ แผงมุมมอง และการตัด
- [แผนที่โลก](map.md): หาสถานที่ เปิดใน 3D ค้นหาทั่วทั้งโลก
- [ปั้นและระบาย](terrain.md): แปรงพื้นดิน แสตมป์ และ ไม่จำกัด
- [ภูมิประเทศ](landform.md): ภูมิประเทศทั้งรูปในคลิกเดียว จากสูตรของคุณเอง (เนินเขา หลุมอุกกาบาต ที่ราบสูง
  คูน้ำ) จากตัวสร้างภูเขา (ยอดเขา สันเขา และภูเขาไฟ ที่เกินขีดจำกัดของเกม) หรือจากรูปภาพ
- [เส้นทาง](path.md): ถนน ทางลาด และแม่น้ำ ไปตามเส้น
- [มาสก์](masks.md): จำกัดเครื่องมือใดก็ได้ ให้อยู่ในไบโอม ความสูง ความชัน หรือการระบาย การ์ดของมาสก์
  ยังมีสวิตช์ ไม่จำกัด ด้วย
- [การวัดและชั้นซ้อนทับ](measure.md): ระยะทาง ความชัน สีความชัน และเส้นชั้นความสูง
- [ขอบเขต การคัดลอกและวาง](area.md): ปรับราบหรือระบาย ในกล่องหรือรูปหลายเหลี่ยม เลือกวัตถุข้างใน
  คัดลอกและวาง ปลูกคืน หรือกู้คืนจากข้อมูลสำรอง
- [จัดวาง](place.md): ต้นไม้ หิน พืชผล และจุดเกิด
- [ก่อสร้าง](build.md): ชิ้นส่วนที่ผู้เล่นสร้าง ทีละชิ้นหรือเรียงตามเส้น พร้อมแถบก่อสร้าง
- [เลือก](select.md): เลือก ย้าย หมุน คัดลอก แทนที่ และลบวัตถุ รวมถึงดูข้างใน
- [เวิร์กช็อป](workshop.md): ก่อสร้างบนแปลงว่าง แล้วเก็บไว้เป็นพิมพ์เขียว
- [ดันเจี้ยน](dungeons.md): สร้างดันเจี้ยน หรือแก้ไขห้องของเกมทีละห้อง
- [โลกใหม่](new-world.md): ดูโลกของซีด ก่อนที่โลกนั้นจะมีอยู่ แล้วสร้างขึ้นมา
- [โหมดไลฟ์](live-mode.md): นำไปใช้แบบไลฟ์ อัตโนมัติ โหลดใหม่ และผู้เล่น ขณะที่เกมรันอยู่
- [สคริปต์](scripting.md): ปั้น ระบาย และเติมพื้นที่ ด้วยสคริปต์ C#
- [Claude](claude.md): สิ่งที่ Claude ทำได้ในเอดิเตอร์ และข้อจำกัด

## หลักการทำงาน

- [พื้นที่และโซน](concepts/areas-and-zones.md): ทำไมเอดิเตอร์ จึงเปิดโลกทีละบล็อก
- [การบันทึกและประวัติ](concepts/saving-and-history.md): การเปลี่ยนแปลงที่รออยู่ การบันทึก
  การนำไปใช้แบบไลฟ์ การเลิกทำ และข้อมูลสำรอง
- [ขีดจำกัดของพื้นดิน](concepts/ground-limits.md): ขีดจำกัด 8 m ของเกม และวิธีที่เอดิเตอร์ทำได้เกินนั้น
- [การแก้ไขแบบไลฟ์](concepts/live-editing.md): วิธีที่เอดิเตอร์ สื่อสารกับเกมที่กำลังรัน
- [วัตถุ](concepts/objects.md): วัตถุคืออะไร การสแนป การตรวจการรับน้ำหนัก กฎการเติบโต และจุดเกิด
- [ดันเจี้ยนในเกม](concepts/dungeons.md): วิธีที่เกมเก็บดันเจี้ยน และวิธีที่ตัวสร้าง สร้างดันเจี้ยนขึ้นมา
- [ความปลอดภัย](concepts/safety.md): สิ่งที่เอดิเตอร์เขียน และทำไมไม่มีอะไร ออกจากคอมพิวเตอร์ของคุณ
