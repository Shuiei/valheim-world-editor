# ให้ Claude ปั้นพื้นดินหรือก่อสร้าง

เชื่อมต่อ Claude Code หรือ Claude Desktop กับเอดิเตอร์ แล้วสั่ง Claude ด้วยคำพูดธรรมดา ให้ปั้นพื้นดิน
ปลูก หรือก่อสร้าง

**สิ่งที่ต้องมี:** เอดิเตอร์ และ [Claude Code](https://claude.com/claude-code) หรือ Claude Desktop บนคอมพิวเตอร์เครื่องเดียวกัน

1. ที่หน้าเริ่มต้นของเอดิเตอร์ เปิด **การตั้งค่า** แล้วหาส่วน **Claude**
2. เปิด **อนุญาตให้ Claude เชื่อมต่อ** ไม่บังคับ: เปิด **Claude รันสคริปต์ได้** เพื่อให้ Claude เขียนและรัน
   สคริปต์ C# ได้ (สคริปต์รันด้วยสิทธิ์ของคุณ บนคอมพิวเตอร์เครื่องนี้ ถ้าไม่แน่ใจ ให้ปิดไว้)
3. กด **บันทึก** (การตั้งค่า จะปิดลง) แล้วเปิด **การตั้งค่า** อีกครั้ง: ส่วนนั้นจะแสดง
   "Listening on http://127.0.0.1:5731/mcp" (รอรับการเชื่อมต่อ)
4. เพิ่มเอดิเตอร์ใน Claude ครั้งเดียว:
   - **Claude Code:** กด **คัดลอก** ข้างคำสั่ง วางลงในเทอร์มินัล แล้วรัน
   - **Claude Desktop:** กด **คัดลอก** ข้างบรรทัดการกำหนดค่า เพิ่มลงใน Claude Desktop → Settings →
     Developer → **Edit Config** (`claude_desktop_config.json`) แล้วรีสตาร์ต Claude Desktop
5. ในเอดิเตอร์ เปิดพื้นที่ของโลกใน 3D หรือเปิดเวิร์กช็อป
6. สั่ง Claude เช่น: "ปรับพื้นให้ราบเป็นสี่เหลี่ยม 40 m ตรงกลางพื้นที่ ปูหิน แล้ววางคบเพลิง
   เป็นวงรอบ"
7. ดู Claude ทำงานในมุมมอง 3D แต่ละขั้นตอนของ Claude จะแสดงใน **ประวัติ** เป็น "Claude: …"
8. เก็บผลไว้ด้วย **บันทึกลงโลก** **นำไปใช้แบบไลฟ์** หรือ **บันทึกพิมพ์เขียว** หรือย้อนกลับ (ด้านล่าง)

## ตรวจว่าได้ผล

- ใน Claude Code คำสั่ง `/mcp` แสดง **valheim-editor** ว่าเชื่อมต่อแล้ว
- คำตอบแรกของ Claude อธิบายสิ่งที่เปิดอยู่ในเอดิเตอร์
- จำนวนที่รออยู่ในแถบด้านบน เพิ่มขึ้นตามการเปลี่ยนแปลงของ Claude ไม่มีอะไรถูกเขียน
  จนกว่าคุณจะบันทึกหรือนำไปใช้

ถ้า Claude บอกว่าเข้าถึงเอดิเตอร์ไม่ได้ ดู [Claude เชื่อมต่อไม่ได้](../help/troubleshooting.md#claude-เชอมตอไมได)

## เลิกทำ

- `Ctrl+Z` ย้อนขั้นตอนล่าสุด ไม่ว่าของ Claude หรือของคุณ
- **ย้อนการเปลี่ยนแปลงของ Claude** ที่ด้านบนของ ประวัติ จะนำทุกขั้นตอนที่ Claude ทำ ในพื้นที่ที่เปิดอยู่ออก
  และเก็บขั้นตอนของคุณไว้
- **ทิ้ง** ทิ้งทุกอย่างที่ยังไม่ได้บันทึก
- ถ้าไม่ให้ Claude เข้าถึงเอดิเตอร์อีก ให้ปิด **อนุญาตให้ Claude เชื่อมต่อ** แล้วกด **บันทึก**
  กด **โทเค็นใหม่** แล้ว **บันทึก** จะล็อกสำเนาของคำสั่งเก่าทั้งหมด ไม่ให้เข้าได้
