# สำรองโลกก่อนแก้ไข

ทำสำเนาโฟลเดอร์ของโลก ที่คุณย้อนกลับไปใช้ได้เสมอ ไม่ว่าโลกจะเป็นอย่างไร หลังจากนั้น

**สิ่งที่ต้องมี:** ชื่อของโลก และปิด Valheim ไว้ (หรือหยุดเซิร์ฟเวอร์ ที่รันโลกนั้นไว้)

1. ปิด Valheim หรือหยุดเซิร์ฟเวอร์ เกมที่รันอยู่ จะเขียนโลกไปเรื่อยๆ สำเนาที่ทำขณะเกมรัน
   จึงอาจเป็นของเก่าครึ่งหนึ่ง ของใหม่ครึ่งหนึ่ง
2. หาโฟลเดอร์ของโลก: ที่หน้าเริ่มต้นของเอดิเตอร์ คลิก **โลกที่บันทึกไว้** แล้ววางเมาส์เหนือการ์ดของโลก
   คำแนะนำเครื่องมือ จะลงท้ายด้วยโฟลเดอร์ เช่น `~/.config/unity3d/IronGate/Valheim/worlds_local/Midgard`
3. เปิดโฟลเดอร์ที่เก็บโลกนั้น (`worlds_local`) ในตัวจัดการไฟล์ ตำแหน่งที่ใช้กันทั่วไปคือ:
   - Windows: `%USERPROFILE%\AppData\LocalLow\IronGate\Valheim\worlds_local`
   - Linux: `~/.config/unity3d/IronGate/Valheim/worlds_local` (Valheim ผ่าน Proton:
     `<Steam library>/steamapps/compatdata/892970/pfx/drive_c/users/steamuser/AppData/LocalLow/IronGate/Valheim/worlds_local`)
   - macOS: `~/Library/Application Support/IronGate/Valheim/worlds_local`
   - เซิร์ฟเวอร์เฉพาะ: `<savedir>/worlds_local` บนเซิร์ฟเวอร์
4. คัดลอกโฟลเดอร์ของโลก (`Midgard`) แล้ววางสำเนา ในโฟลเดอร์ `worlds_local` เดียวกัน
5. เปลี่ยนชื่อสำเนาเป็น `<World>_backup_<date>` เช่น `Midgard_backup_2026-10-22` ใช้ชื่อโลกให้ตรงทุกตัว
   ตามด้วย `_backup_`

> [!TIP]
> เมื่อตั้งชื่อแบบนี้ สำเนาจะอยู่ข้างโลก และเอดิเตอร์จะแสดง เป็นข้อมูลสำรอง ใน **กลับไปใช้ข้อมูลสำรอง**
> ของเครื่องมือ ขอบเขต คุณจึงนำพื้นที่หนึ่ง กลับมาจากสำเนานี้ได้ในภายหลัง: ดู
> [คืนสภาพพื้นที่หนึ่ง จากข้อมูลสำรอง](restore-from-backup.md)

## ตรวจว่าได้ผล

- สำเนามีไฟล์เหมือนโลก: `_main.<n>.chunks` `.db2` `.fwl2` `.ok` และไฟล์ `.chunk`
- ที่หน้าเริ่มต้น **โลกที่บันทึกไว้** จะแสดงสำเนาด้วย ภายใต้ชื่อของสำเนาเอง ให้เปิดตัวโลกเพื่อแก้ไข
  ไม่ใช่สำเนา
- ในมุมมอง 3D ของโลก **กลับไปใช้ข้อมูลสำรอง** ของเครื่องมือ [ขอบเขต](../area.md) จะแสดงสำเนาเป็น
  **เอดิเตอร์ · \<date\>**

## เลิกทำ

สำเนาไม่เปลี่ยนอะไรในโลก: ลบโฟลเดอร์ของสำเนา เมื่อไม่ต้องใช้แล้ว

หากต้องการคืนทั้งโลก ให้เป็นเหมือนในสำเนา:

1. ปิด Valheim หรือหยุดเซิร์ฟเวอร์
2. ย้ายโฟลเดอร์ของโลก (`Midgard`) ออกจาก `worlds_local` เช่น ไปไว้ที่เดสก์ท็อป
   (ลบทิ้งภายหลัง เมื่อแน่ใจแล้ว)
3. เปลี่ยนชื่อสำเนา (`Midgard_backup_2026-10-22`) เป็นชื่อของโลก (`Midgard`)
4. เปิดเกม: เกมจะโหลดโลก ตามที่เป็นตอนที่คุณคัดลอก

เกมเก็บข้อมูลสำรองของตัวเอง ไว้ข้างโลกด้วย (`<World>_backup_auto-<date>`) เอดิเตอร์แสดงข้อมูลสำรองเหล่านี้ เป็น
**เกม · \<date\>**
