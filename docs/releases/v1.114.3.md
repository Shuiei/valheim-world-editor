Claude from another computer, and safer scripts: Settings → Claude has an **Address**, so a Claude on another
computer of your network can work with the editor, and every script Claude writes is shown to you before it runs. The
WorldEditorBridge plugin can no longer be reached from the internet, whatever its `BindAddress`. Restore now takes
saved No limit ground all the way back to the generated ground. The Railroads add-on follows Railroads 0.3.6, with its
drawbridges, feedback post and couplers.

This release covers 1.114.0 to 1.114.3. The WorldEditorBridge plugin changed in 1.114.2: update it on your server.

## Added

- **Claude from another computer.** Settings → Claude has an **Address**: `127.0.0.1` (this computer only) as before, or `0.0.0.0` (every network) or one of this computer's networks, picked from a list that names each (or typed), so a Claude on another computer can connect, with the token. The command to add the editor to Claude Code follows the address, and with every network a line under it gives the addresses another computer uses. Off this computer the connection is not encrypted (plain HTTP), and Settings says so. Only computers on this computer's own network or VPN (Tailscale) can connect, never from the internet, and a Claude on another computer cannot run scripts.

## Fixed

- **Claude shows you each script before it runs.** With **Claude may run scripts** on, every script Claude writes now opens a window with its code, to run or refuse (a dry run and its run ask once). Text in a world, such as a sign another player wrote, could otherwise talk Claude into running a harmful one unseen.
- **Restore takes saved No limit ground away.** Once ground past the game's ±8 m was saved, the Restore brush and the Area tool's **Restore the ground** brought the ground back only to that saved shape, not to the ground the world generated. They now go all the way back, and the next save takes away the ground discs that are no longer needed.

## WorldEditorBridge

- **Never reachable from the internet.** Only the machine the plugin runs on, its local networks and VPNs such as Tailscale can connect, even with `BindAddress` changed from `127.0.0.1`, and the server's log warns that the token then travels unencrypted. [Live mode](https://github.com/Shuiei/valheim-world-editor/blob/main/docs/live-mode.md#without-ssh) explains how to connect from another computer in the house without SSH. The token is only taken from the editor's header, no longer from the address, where it could end up in logs.

## Add-ons

- **Railroads 0.3.0.** Follows Railroads 0.3.6. Its drawbridge is drawn with its leaves, chains and counterweights, lowered or raised as the mod keeps it, and **Raised** in the inspector raises or lowers it; trains placed on it stand on its track. The feedback post is drawn and offered in the Build panel, and the old station is offered again. Couplers are drawn again, apart from each vehicle's body as the mod now builds them. A pasted or moved train forgets who sent it, and the inspector names what a piece was paid with.
