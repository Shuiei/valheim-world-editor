Everything signed, everywhere: the WorldEditorBridge plugin, every add-on and the SDK for mod authors now carry the
maintainer's signature, as the Windows program does, for fewer antivirus warnings. The Windows download on Nexus Mods
is now the same signed package as on GitHub. Nothing else changed.

This release covers 1.114.4 and 1.114.5. The WorldEditorBridge plugin works as in 1.114.3; only its DLLs are now
signed.

The Windows program, the plugin, the add-ons and the SDK carry an Authenticode signature (Certum). Each file comes with a Sigstore signature (`<file>.sigstore.json`); [SECURITY.md](https://github.com/Shuiei/valheim-world-editor/blob/main/SECURITY.md) says how to check a download.

## Fixed

- **The plugin and the add-ons are signed too.** Like the Windows program, the WorldEditorBridge plugin, every add-on and the SDK for mod authors now carry the maintainer's signature, for fewer antivirus warnings.
- **The Windows download on Nexus Mods is signed.** It had the program and one of its libraries unsigned, unlike the one on GitHub, which made antivirus scans flag it. Both sites now get the same signed download.

## WorldEditorBridge

- **Signed.** The plugin's DLLs carry the maintainer's signature, as the Windows program does. Nothing else changed: the 1.114.3 plugin still works with this editor.

See the [CHANGELOG](https://github.com/Shuiei/valheim-world-editor/blob/main/CHANGELOG.md) for the details.
