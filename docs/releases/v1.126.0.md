With the Expand World add-on, the editor now places what the Expand World mods define: a persistent event started where you click, and a "custom object", a game object carrying one of the mods' data entries.

This release also brings 1.125.0 and 1.125.1, which were not published on their own. v1.124.1 reached Nexus Mods with the plugin only: the editor's downloads are there again from this release.

The WorldEditorBridge plugin is unchanged: the 1.114.5 plugin works with this editor.

## Added

- **Persistent events, started where you want them.** Expand World Data's persistent events (`expand_persistent_events.yaml`) are long lasting events over a part of the world, which the game starts by itself where its rules allow. The new **Persistent event** tool, under **Mods** on the 3D editor's rail, starts the one you choose where you click, at the size you set, and places the objects the event makes round it; a click inside an active event can stop it instead. Active events are ringed while the tool is chosen, each start and stop is one step of the history, and they are written with the world when you save. In a saved world only: a running game keeps its own list. The event's location, its messages and commands are left to the game. See [the add-on's page](https://github.com/Shuiei/valheim-world-editor/blob/main/addons/ExpandWorld/README.md#the-persistent-event-tool).
- **Custom objects, placed and edited.** The Expand World mods have no objects of their own: a custom object is a game object with a data entry, a named set of values that Expand World Prefabs' rules set, spawn with or look for. The new **Custom object** tool, under **Mods**, lists the entries of your data files and rules and gives the one chosen to an object: a new one placed where you click, among the objects the rules use an entry on, or any object you click. A renamed, unbreakable, flattened block a rule looks for is then found by the rule as if the mod had made it. Values the mod works out as it makes an object (a parameter, a list, a range, items) are left out, and the tool's card names them. See [the add-on's page](https://github.com/Shuiei/valheim-world-editor/blob/main/addons/ExpandWorld/README.md#the-custom-object-tool).
- **For mod authors:** a tool's edit can start and stop the game's persistent events (`ToolEdit.StartEvent`, `StopEvent`), and the area a tool is handed lists the active ones (`IWorldEvents`).

## Fixed

- **A mod tool's size by axis is kept.** An object a mod's tool gives a size that differs by axis (a flattened piece) was saved with one size on every axis.
