Portals on the map and fewer antivirus warnings: the map shows every **portal** of the world, the line between the two
of each tag and their tags, off at first since it is a spoiler; on Windows every library that comes with the editor is
signed. The ValheimRAFT and Railroads add-ons follow the mods' latest versions: ValheimRAFT 5.1.1 and Railroads 0.2.9,
whose trains have names.

This release covers 1.112.2 and 1.113.0. The WorldEditorBridge plugin is unchanged: the 1.112.1 plugin still works
(its package is renumbered to match).

## Added

- **Show portals and their links on the map.** Every portal of the world as a violet dot (hollow when it has no partner), a line between the two portals of each tag (the pair the game joins; a pair the save holds joined stays together), and the tags beside them when zoomed in. The switch's text counts the portals, the linked pairs and the portals alone. Off at first (spoiler). Portals a mod adds count too, by their name.

## Fixed

- **Fewer antivirus warnings on Windows.** Every library that comes with the editor is now signed, and a web-server file the editor never used is no longer in the download.

## Add-ons

- **ValheimRAFT 0.2.0.** Follows ValheimRAFT 5.1.1, checked on a server running it: its new iron centre bows are listed under Hull in the Build panel, and the inspector names a vehicle's build mode, its hull shape and the dock clamp it is docked at. A pasted vehicle is no longer docked at the original's clamp, and a mirrored copy no longer keeps the original's hull shape.
- **Railroads 0.2.0.** Follows Railroads 0.2.9: the inspector shows a train's name, which you can change, and the number the server gave it; a pasted train keeps its name and gets a number of its own. The locomotive is drawn with the name boards on its boiler, and the portal wagon as the mod now builds it.
