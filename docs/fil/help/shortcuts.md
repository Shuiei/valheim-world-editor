# Mga shortcut

Bawat key at aksiyon ng mouse ng editor, nakagrupo ayon sa ginagawa mo. Ipinapakita ng button na **?** sa top bar
(o `F3`) ang mga pangunahin habang nagtatrabaho ka.

Sa 3D editor lang gumagana ang mga key: hindi habang nagta-type ka sa kahon, at hindi sa panimulang pahina o sa mapa ng
mundo (maliban sa `F1`: gumagana ito kahit saan). Sa
Mac, pindutin ang `Cmd` saanman sinasabi ng pahinang ito ang `Ctrl` (nag-a-undo ang `Cmd+Z`, nagdadagdag sa pinili ang
`Cmd`+click) at ang `Option` para sa `Alt`.

## Camera

| Key o mouse | Aksiyon |
|---|---|
| Kanang drag | Iikot ang tanaw. Sa paglakad at paglipad: tumingin sa paligid. |
| Wheel | Mag-zoom, mula 3 m hanggang 3 km mula sa puntong tinitingnan mo. |
| Gitnang drag | Igalaw ang tanaw. |
| `Space` + kaliwang drag, `Shift` + kanang drag | Igalaw ang tanaw, sa anumang tool (madaling gamitin kung walang gitnang button). |
| Kaliwang drag (tool na **Tanaw**) | Igalaw ang tanaw. |
| `W` `A` `S` `D` o ang mga arrow key | Gumalaw. Habang mas naka-zoom out ka, mas mabilis. Hindi habang pinipindot ang `Ctrl` o `Alt`. |
| `F` | Maglakad sa taas ng mata, saka lumipad, saka bumalik sa karaniwang tanaw, sa bawat tool. |
| `Shift` (paglakad) | Tumakbo: 12 m/s sa halip na 6. |
| `Space` / `C` (paglipad) | Pataas / pababa, tagos din sa lupa (papasok sa mga tunnel at bodega ng mod). `Shift`: 45 m/s sa halip na 15. |

Habang naglalakad o lumilipad, hindi nagzo-zoom ang wheel at hindi iginagalaw ng drag ang tanaw. Tingnan ang
[Maglakad at lumipad](../editor-basics.md#lakad-at-lipad).

## Mga panel at pag-save

| Key | Aksiyon |
|---|---|
| `V` | Buksan o isara ang panel na **Tanaw**. |
| `L` | Buksan o isara ang **Kasaysayan**. |
| `?` (`Shift+/`) o `F3` | Buksan o isara ang help card na **Mga kontrol**. |
| `F1` | Ang Help window sa pahina ng ginagamit na tool (tingnan ang [Ang Help window](#ang-help-window)). Binubuksan ng maliit na **?** sa itaas ng bawat panel ang pahina ng panel na iyon. |
| `Ctrl+S` | **I-save sa mundo** (naka-save na mundo), **I-apply nang live** (live), **I-save ang blueprint** (ang Gawaan). |

## Pumili ng tool

| Key | Tool |
|---|---|
| `1` `2` `3` `4` `5` | Itaas, Ibaba, Patagin, Pakinisin, Ibalik |
| `0` | Natural |
| `O` (ang letra) | Agnasin |
| `6` `7` `8` `9` | Ang brush na **Pintura** na may Hubad na lupa, Bungkalin, Sementado, Alisin pintura |
| `B` | Rehiyon |
| `P` | Daan |
| `T` | Paglagay (**Pagtayo** sa Gawaan) |
| `U` | Pagtayo |
| `G` | Lupain |
| `E` | Pagpili |
| `M` | Pagsukat |
| `H` o `Esc` | Tanaw (`Esc` lang kapag wala na itong ibang kakanselahin, tingnan ang [Paano gumagana ang Esc](#paano-gumagana-ang-esc)) |

Gumagana rin ang mga digit ng number pad. Walang key ang **Dungeon**, **Script** at **Blueprints**: i-click ang mga ito
sa rail. Sa Gawaan, `U` o `T`, `E` at `H` o `Esc` lang ang pumipili ng tool.

## I-undo, kopyahin at i-paste

| Key | Aksiyon |
|---|---|
| `Ctrl+Z` | I-undo ang huling pagbabago. |
| `Ctrl+Y` o `Ctrl+Shift+Z` | I-redo ito. |
| `Ctrl+C` | Kopyahin ang kahon o polygon ng Rehiyon, o ang mga napiling object (mga tool na Rehiyon at Pagpili). |
| `Ctrl+X` | Gupitin: ang parehong kopya, saka umaalis sa mundo ang mga object bilang isang hakbang (nananatili ang lupa). |
| `Ctrl+V` | Simulang i-paste ang clipboard, mula sa anumang tool. |
| `[` / `]` | Paliitin / palakihin ang Diyametro nang 1 m (1 hanggang 30 m). |

## Pumili ng mga object

Gumagana ang mga ito sa tool na **Pagpili** (`E`). Ganoon din pumipili ng object ang click sa tool na **Tanaw**.

| Key o mouse | Aksiyon |
|---|---|
| Click | Piliin ang object na iyon nang mag-isa. Mag-click ulit sa parehong puwesto: ang susunod na object sa likod nito. |
| `Ctrl`+click | Idagdag ang object, o alisin ito kung napili na. |
| `Shift`+click | Alisin ang object sa pinili. |
| `Ctrl+Shift`+click | Idagdag ang bawat ipinapakitang object sa isang hanay, mula sa huling kini-click hanggang dito. |
| Double-click | Piece ng gusali: ang buong gusali. Bahagi ng barko o ibang magkakabit na grupo: ang buong grupo. Anumang ibang object (chest, karatula, puno): ang object na iyon, bukas ang Inspector nito. Sa tool na Tanaw, lumilipat sa Pagpili ang double-click sa object. |
| Drag sa bakanteng lupa | Piliin ang nasa loob ng kahon (o ng balangkas sa lupa, kapag ganoon ang **Iguguhit ng drag ang**). `Ctrl`: idagdag sa pinili. `Shift`: alisin. |
| `Alt` + drag | Pareho, pero nagsisimula rin sa ibabaw ng mga object (hindi natatamaan ang mga object). |
| `Ctrl+A` / `Alt+A` | Piliin ang bawat ipinapakitang object / alisin ang pinili. |
| `Ctrl+I` | Baligtarin ang pinili. |
| `Ctrl+H` / `Alt+H` | Itago ang mga napiling object sa tanaw / ipakita ulit ang mga ito. |
| `Alt+Z` | I-on o i-off ang **Pumili nang tagos**: kinukuha rin ng kahon ang nakatago sa likod ng iba. |
| `Shift+F` o `.` ng number pad | I-frame ang pinili. |

## Bawat tool

### Mga brush ng lilok at pintura

| Key o mouse | Aksiyon |
|---|---|
| Kaliwang drag | Ipahid ang brush sa lupa. |
| `Alt`+click | Kunin ang taas ng lupa roon bilang taas ng Patagin, at lumipat sa **Patagin**. |
| `Alt+Shift`+click | Itakda ang saklaw ng taas ng [Mask](../masks.md) sa 2 m sa itaas at ibaba ng puwestong iyon (pati sa tool na Daan). |

### Rehiyon

| Key o mouse | Aksiyon |
|---|---|
| Drag (Kahon) | Iguhit ang kahon. |
| Click (Polygon) | Magdagdag ng punto. Double-click: isara ang polygon. |
| `Enter` | Isara ang polygon na iginuguhit; kapag tapos na ang pinili, gawin ang napiling aksiyon. |
| `Enter`, saka `Del` | Kapag napili ang **Mga object**: piliin ang mga object sa loob, saka burahin ang mga ito sa tool na Pagpili. |
| `Backspace` | Tanggalin ang huling punto ng polygon. |
| `Esc` | Alisin ang pinili (ang kahon o polygon). |

### Daan

| Key o mouse | Aksiyon |
|---|---|
| Click | Magdagdag ng punto. |
| I-drag ang linya | Magdagdag ng punto roon at ilipat ito. |
| I-drag ang punto | Ilipat ito. |
| `Ctrl`+click sa punto | Tanggalin ito. |
| `Alt`+click | Kunin ang taas ng lupa roon bilang taas ng daan (Rampa: ang simula nito). |
| `Ctrl+Alt`+click | Rampa: kunin ang taas bilang dulo nito. |
| `Alt+Shift`+click | Itakda ang saklaw ng taas ng [Mask](../masks.md), gaya sa brush. |
| `Enter` | I-apply ang daan. |
| `Backspace` | Tanggalin ang huling punto. |
| `Esc` | Alisin ang linya. |

### Paglagay

| Key o mouse | Aksiyon |
|---|---|
| Kaliwang drag (Brush) | Maglagay ng mga object sa ilalim ng brush. `Shift` + drag: tanggalin ang mga ito. |
| Click (Linya, Polygon) | Magdagdag ng punto. I-drag ang balangkas: magdagdag ng punto roon. I-drag ang punto: ilipat ito. `Ctrl`+click sa punto: tanggalin ito. |
| I-double-click ang huling punto | Maglagay sa kahabaan ng hugis. |
| Drag (Grid, mga hugis na linya) | Iguhit ang kahon ng grid, o ang hugis mula sa isang dulo hanggang sa kabila. |
| `Alt`+click | Kunin ang taas doon bilang **Elebasyon**. |
| `Enter` | Maglagay sa kahabaan ng linya, bilog o parihaba, o sa loob ng grid o polygon. |
| `Backspace` | Tanggalin ang huling punto ng linya o polygon. |
| `Esc` | Alisin ang hugis na iginuguhit, o kanselahin ang **Pumili mula sa mundo**. |
| `N` | Bagong random na ayos. |
| `R` | Iikot nang kapat ng ikot ang preview, ang iginuhit na grid o ang polygon. |
| `,` / `.` o `Alt` + wheel | Iikot nang 15° ang preview, ang iginuhit na grid o ang polygon (`Shift`, mas pino: 1°). |
| `PgUp` / `PgDn` o `Ctrl` + wheel | Itaas o ibaba nang 0.5 m ang inilalagay mo (`Shift`, mas pino: 0.1 m). |
| I-click ang object (**Pumili mula sa mundo**) | Kunin ang uri nito. Idinadagdag ito ng `Shift`+click sa mga napiling uri. |

### Pagtayo, I-paste at paglipat ng pinili: ang mga hakbang ng bar ng Pagtayo

Pareho ang mga key na ginagamit ng [Pagtayo](../build.md), I-paste at Pagpili para mag-ikot at mag-angat, ayon sa mga
hakbang na itinakda sa [bar ng Pagtayo](../build.md#ang-bar-ng-pagtayo) (**Iikot nang**, 22.5° sa simula; **Angat**, 0.5 m
sa simula). Laging pinapapino ng `Shift` ang hakbang.

| Key o mouse | Aksiyon |
|---|---|
| `,` / `.` o `Alt` + wheel | Iikot ang piece, ang ipe-paste o ang pinili nang ayon sa hakbang ng **Iikot nang** (`Shift`: 1°). |
| `PgUp` / `PgDn` o `Ctrl` + wheel | Iangat o ibaba ito ayon sa hakbang ng **Angat** (`Shift`: ikalimang bahagi nito). |

### Pagtayo (mga mundo, ang Gawaan, at pagtatayo sa dungeon)

| Key o mouse | Aksiyon |
|---|---|
| Click | Ilapag ang piece (**Ilatag**: **Isang piece**), o magdagdag ng punto (**Linya**). |
| Drag | Isang hanay ng piece (**Isang piece**); ang bilog, parihaba o grid (**Ilatag**). |
| Pindutin nang matagal ang `Alt` | Ilagay ang piece nang bawat kapat na metro, nang hindi kumakapit. |
| `R` | Iikot nang kapat ng ikot ang piece. |
| `Q` / `E` | Kapag **Mano-mano** ang **Kapit**: ang nakaraan / susunod na snap point ng piece. |
| `Shift` + kanang click | Tanggalin ang piece sa ilalim ng pointer. |
| Gitnang click | Magtayo gamit ang uri ng piece sa ilalim ng pointer. |
| `Enter` | Ilapag ang linya, bilog, parihaba o grid. |
| `Backspace` | Tanggalin ang huling punto ng linya. |
| `Esc` | Alisin ang linya, hugis o grid na iginuguhit. |

### I-paste

| Key o mouse | Aksiyon |
|---|---|
| Click | Ilapag ang ipe-paste. Mag-click ulit para sa higit pang kopya. |
| `R` | Iikot nang kapat ng ikot. |
| `X` | I-mirror. |
| `Esc` | Ihinto ang pag-paste, balik sa tool na Rehiyon. |

### Ilipat ang pinili (Pagpili)

| Key o mouse | Aksiyon |
|---|---|
| I-drag ang napiling object | Ilipat ang pinili. |
| I-drag ang arrow o ang singsing | Ilipat sa kahabaan ng axis na iyon, o iikot. |
| `R` | Iikot nang kapat ng ikot ang pinili. |
| `End` | Ibagsak ito sa lupa. |
| `Del` | Burahin ang mga napiling object. |
| `I` | Buksan ang Inspector ng napiling object (isang object ang napili). |
| `Esc` | Kanselahin ang kasalukuyang paglipat, o ang kahon o balangkas na iginuguhit. |

### Iba pang tool

| Tool | Key o mouse | Aksiyon |
|---|---|---|
| Lupain | Click | Ilagay roon ang anyong-lupa: ang hugis ng pormula, ang bundok o ang larawan. |
| Pagsukat | Mag-click ng dalawang punto | Sukatin sa pagitan nila. Inaalis ng `Esc` ang sukat. |
| Dungeon | `R` | Iikot ang silid na idaragdag: kumakabit ito sa susunod nitong bukasan. |
| | `Del` | Burahin ang napiling silid. |
| Script | `Ctrl+Enter` | Patakbuhin ang script (sa kahon ng code). |
| Inspector | `Esc` | Isara ito. |
| Tool ng mod | Sariling mga key nito | Ang tool sa ilalim ng **MODS** sa rail ang unang kumukuha ng mga key na ginagamit nito; gumagana gaya ng dati ang iba. |

## Paano gumagana ang Esc

Ginagawa ng `Esc` ang una sa mga ito na angkop, saka humihinto:

1. Kinakansela ang pagpili ng uri gamit ang **Pumili mula sa mundo**.
2. Inihihinto ang pag-paste (balik sa tool na Rehiyon).
3. Isinasara ang Inspector.
4. Kinakansela ang ginagawa ng tool: paglipat sa Pagpili, kahon o balangkas na iginuguhit, hugis ng Paglagay o linyang
   inilalatag gamit ang Pagtayo, kahon o polygon ng Rehiyon, mga punto ng Daan, isang sukat.
5. Lumilipat sa tool na Tanaw.

## Ang mapa ng mundo at bagong mundo

| Mouse | Aksiyon |
|---|---|
| Drag | Igalaw ang mapa. |
| Wheel | Mag-zoom papunta sa mouse. |
| Click | Pumili ng puwesto (ang zone para sa **I-edit sa 3D**). |
| Double-click (mapa ng bagong mundo) | Ipakita ang buong mundo. |
| `Enter` sa kahon ng paghahanap | Maghanap. |

## Ang Help window

| Key | Aksiyon |
|---|---|
| `F1` | Buksan ang tulong sa ginagamit mo: ang tool, ang Inspector, ang mapa, ang panimulang pahina… (anumang pahina). |
| `Ctrl+F` | Maghanap sa tulong. |
| `Alt+Left` / `Alt+Right` | Bumalik / sumulong. |
| `Esc` | Isara ang pinalaking larawan, kung hindi, alisan ng laman ang paghahanap. |
| `Enter` sa kahon ng paghahanap | Buksan ang unang nahanap na pahina. |
