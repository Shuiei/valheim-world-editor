# Glosaryo

Ang mga salitang ginagamit ng editor at ng tulong na ito, mula A hanggang Z. Bawat entry ay may link kung saan ito
ipinapaliwanag.

**Add-on.** Hiwalay na download na nagtuturo sa editor tungkol sa isang mod (Expand World, Riverheim, Tunnelheim,
Railroads, ValheimRAFT), na ina-unpack sa `addons` folder katabi ng editor. Tingnan ang
[I-install ang editor](../start/install.md#mga-add-on-para-sa-mga-mod).

**Alt biome.** Isang variant ng biome na ibinibigay ng laro sa ilang lugar mula sa seed (Dark Meadows, Rock Black
Forest…), kasama ang tumutubo roon. Pinapangalanan ito ng readout ng mapa. Tingnan ang [Rehiyon, kopyahin at i-paste](../area.md) (Muling patubuin ang kalikasan).

**Angkla.** Ang gitna ng plot ng Gawaan, sa antas ng lupa: ang puntong pinagsusukatan ng blueprint ng Homestead sa
bawat piece. Tingnan ang [Ang Gawaan](../workshop.md).

**Area.** Ang bloke ng mga zone na nakabukas sa 3D window, mula 3 × 3 hanggang 17 × 17 zone. Tingnan ang
[Ang area](../concepts/areas-and-zones.md#ang-area).

**Auto.** Isang switch ng live mode na ina-apply ang bawat pagbabago sa laro sa sandaling gawin mo ito. Tingnan ang
[Live mode](../live-mode.md).

**Backup.** Kopya ng folder ng mundo, pinangalanang `<World>_backup_<something>` katabi nito. Gumagawa ang laro ng
sarili nito (`_backup_auto-`); ginagawa mo ang sa iyo bago mag-edit. Tingnan ang
[Mga backup](../concepts/saving-and-history.md#mga-backup) at
[Mag-backup ng mundo bago mag-edit](../guides/back-up-a-world.md).

**Bar ng Pagtayo.** Ang bar ng mga setting ng pagtatayo katabi ng tool rail, kahati ng Pagtayo, Pagpili at
I-paste: Kapit, Grid, Iikot nang, Angat at Itinayo ni. Tingnan ang
[Ang bar ng Pagtayo](../build.md#ang-bar-ng-pagtayo).

**BepInEx.** Ang mod loader ng Valheim. Kailangan ito ng laro o server na nagho-host ng mundo, kasama ang plugin na
WorldEditorBridge, para sa live na pag-edit. Tingnan ang
[I-install ang editor](../start/install.md#ang-plugin-para-sa-live-na-pag-edit).

**Biome.** Isang uri ng kalupaan sa Valheim: Meadows, Black Forest, Swamp, Mountain, Plains, Mistlands, Ashlands, Deep
North, Ocean. Kayang limitahan ng [Mask](../masks.md) ang isang tool sa isa sa mga ito.

**Blueprint.** Isang naka-save na gusali, sa format ng mod na Homestead: itinayo sa Gawaan o kinopya mula sa mundo,
ipine-paste sa kahit anong mundo. Tingnan ang [Ang Gawaan](../workshop.md).

**Bridge.** Maikli para sa WorldEditorBridge, ang plugin ng editor sa laro. Tingnan ang **Plugin**.

**Brush.** Isang tool na idina-drag mo sa ibabaw ng lupa: ang mga brush ng paglilok (Itaas, Ibaba, Patagin…) at ang
brush na Pintura kasama ang apat na pintura nito (Hubad na lupa, Bungkalin, Sementado, Alisin pintura). May brush
din ang Paglagay. Tingnan ang [Lilok at pintura](../terrain.md).

**Clipboard.** Ang hawak ng huling pagkopya o paggupit, iniingatan hanggang kumopya ka ulit, kahit pagkatapos
mag-restart ng editor. Tingnan ang [Rehiyon, kopyahin at i-paste](../area.md).

**Dock ng Pagtayo.** Ang panel ng tool na Pagtayo sa ibaba ng window, kasama ang mga piece ng laro ayon sa tab, sa
mundo at sa Gawaan. Tingnan ang [Ang dock ng Pagtayo](../build.md#ang-dock-ng-pagtayo).

**Dungeon.** Mga silid na iniingatan ng laro 5000 m sa itaas ng pasukan nila sa lupa: mga crypt, Frost Caves at mga
katulad nito. Tingnan ang
[Paano iniingatan ng laro ang mga dungeon](../concepts/dungeons.md#paano-iniingatan-ng-laro-ang-mga-dungeon).

**Extension.** Code na dala ng isang mod para turuan ang editor tungkol sa mga piece at data nito, ino-on sa
**Mga setting**. Tingnan ang [Para sa mga gumagawa ng mod](../modding.md).

**Folder ng mundo.** Ang folder na may hawak ng isang mundo: `_main.<n>.chunks`, `.db2`, `.fwl2`, `.ok` at ang mga file
na `.chunk`. Nasa `worlds_local` ang mga mundo ng single-player. Tingnan ang
[Magbukas ng mundong wala sa listahan](../guides/open-a-world.md).

**Gawaan.** Isang blangkong plot, sa labas ng anumang mundo, para pagtayuan at para itabi ang gusali bilang blueprint.
Tingnan ang [Ang Gawaan](../workshop.md).

**Ground disc.** Isang di-nakikitang lokasyon na isinusulat ng editor para hawakan ang lupang lampas sa 8 m na
hangganan ng laro. Tingnan ang [Walang limitasyon](../concepts/ground-limits.md#walang-limitasyon).

**Hakbang.** Isang pagbabago sa Kasaysayan: isang stroke ng brush, isang click, isang paste, isang pagpapatakbo ng
script. Ina-undo ng `Ctrl+Z` ang isang hakbang. Tingnan ang
[Mga nakabinbing pagbabago](../concepts/saving-and-history.md#mga-nakabinbing-pagbabago).

**Hiwa (ng view).** Ang slider ng status bar na nagtatago ng bawat object na lampas sa isang taas, para makita at
makapagtrabaho sa loob ng mga gusali. Iba ito sa paggupit papunta sa clipboard (`Ctrl+X`). Tingnan ang
[Hiwa](../editor-basics.md#hiwa).

**Homestead.** Isang mod sa pagtatayo sa Valheim na ang mga blueprint ay sine-save ng editor; kapag nasa laro mo ito,
itinatayo mo ang mga iyon gamit ang hammer. Hindi kailangan para mag-paste ng mga blueprint sa editor. Tingnan ang
[Ang Gawaan](../workshop.md).

**I-reload.** Sa live mode, ang muling pagbasa ng mundo mula sa laro. Tingnan ang [Live mode](../live-mode.md).

**Inspector.** Ang panel na nagpapakita at nagbabago ng hawak ng isang object: mga item ng chest, teksto ng karatula,
tag ng portal. Tingnan ang [Pagpili](../select.md).

**Itapon.** Ang button ng top bar na nag-a-undo ng lahat ng hindi pa naka-save o na-apply. Tingnan ang
[Mag-undo ng hakbang, bawiin ang isang pagbabago, o itapon ang lahat](../guides/undo-changes.md).

**Itinayo ng player.** Isang piece na nagtatala kung sino ang nagtayo nito, gaya ng ginagawa ng laro sa inilalagay ng
hammer. Tingnan ang [Mga piece na itinayo ng player](../concepts/objects.md#mga-piece-na-itinayo-ng-player).

**Itinayo ni.** Ang player na isinusulat bilang nagtayo ng mga piece na itinatayo, ipine-paste o pinapalitan mo,
pinipili sa [bar ng Pagtayo](../build.md#ang-bar-ng-pagtayo). Tingnan ang
[Mga piece na itinayo ng player](../concepts/objects.md#mga-piece-na-itinayo-ng-player).

**Itsura ng laro.** Pagguhit ng mundo gamit ang sariling mga texture at model ng laro, binabasa mula sa Valheim mo.
Naka-off: mga simpleng kulay, mas mabilis. Tingnan ang [Panel na Tanaw](../editor-basics.md#panel-na-tanaw).

**Kasaysayan.** Ang listahan ng mga hakbang mo sa isang mundo (`L`), para i-undo, i-redo o tanggalin ang isa.
Iniingatan pagkatapos ng bawat pag-save o pag-apply, kaya bumabalik ito kapag binuksan mo ulit ang mundo. Tingnan ang
[Kasaysayan](../concepts/saving-and-history.md#kasaysayan).

**Live mode.** Pag-edit ng mundo habang pinapatakbo ito ng laro o server, sa pamamagitan ng plugin. Tingnan ang
[Paano ito kumokonekta](../concepts/live-editing.md#paano-ito-kumokonekta).

**Lokasyon.** Isang lugar na inilalagay ng laro sa mundo kapag ginagawa ito: mga nayon, ang trader, mga altar ng boss,
mga pasukan ng dungeon. Pinapatag ng mga lokasyon ang lupa sa paligid nila. Tingnan ang
[Pinapatag ng mga lokasyon ang lupa](../concepts/ground-limits.md#pinapatag-ng-mga-lokasyon-ang-lupa).

**Lupain.** Isang punso, bunganga, bundok o larawan ng taas na inilalagay nang buo sa lupa, sa isang click ng tool na
Lupain (`G`). Tingnan ang [Lupain](../landform.md).

**Magkakabit na grupo.** Mga object na pinagbubuklod ng isang mod, gaya ng barko at mga bahagi nito; pinipili at
inililipat bilang isa. Tingnan ang [Pagpili](../select.md).

**Marka ng hangganan.** Pula sa lupang umabot sa 8 m na hangganan ng laro. Tingnan ang
[Marka ng hangganan](../concepts/ground-limits.md#marka-ng-hangganan).

**Mask.** Isang card na naglilimita sa isang tool sa lupa ng isang biome, taas, dahilig o pintura. Tingnan ang
[Mask](../masks.md).

**MCP.** Ang paraan ng pagtawag ng Claude Code at Claude Desktop sa mga tool ng editor kapag pinayagan mong kumonekta si
Claude. Tingnan ang [Claude](../claude.md).

**Na-apply.** Ipinadala sa tumatakbong laro gamit ang **I-apply nang live** (o **Auto**). Tinatatakan ng Kasaysayan
ang mga ganitong hakbang ng **na-apply**; maa-undo pa rin ang mga ito. Tingnan ang
[Pag-apply nang live](../concepts/saving-and-history.md#pag-apply-nang-live).

**Nabuong zone.** Isang zone na nagawa na ng laro, dahil may player na lumapit dito. Ang mga nabuong zone lang ang may
data na mapagse-save-an ng editor. Tingnan ang [Mga zone](../concepts/areas-and-zones.md#mga-zone).

**Nakabinbin.** Isang pagbabagong ginawa sa editor at hindi pa naka-save o na-apply. Binibilang ang mga ito ng itaas
na bar. Tingnan ang [Mga nakabinbing pagbabago](../concepts/saving-and-history.md#mga-nakabinbing-pagbabago).

**Naka-lock na gilid.** Ang panlabas na linya ng mga punto ng lupa ng area, na hindi ginagalaw ng mga tool, para
dumugtong ang area sa mga katabi nito. Tingnan ang
[Ang naka-lock na gilid](../concepts/areas-and-zones.md#ang-naka-lock-na-gilid).

**Naka-save na mundo.** Ang folder ng isang mundo sa computer na ito, ine-edit nang nakasara ang laro. Tingnan ang
[Ang window ng editor](../editor-basics.md#ang-panimulang-pahina).

**Naunang session.** Isang hakbang sa Kasaysayan na iningatan mula sa naunang pagpapatakbo ng editor, bumabalik kapag
binuksan mo ulit ang mundo. Tingnan ang [Kasaysayan](../concepts/saving-and-history.md#kasaysayan).

**Paghina.** Kung paano humihina ang lakas ng brush mula sa gitna nito hanggang sa gilid. Tingnan ang
[Lilok at pintura](../terrain.md).

**Pagkapit.** Ang pagdugtong ng mga piece sa kanilang mga punto ng kapit, gaya ng hammer ng laro. Tingnan ang
[Pagkapit](../concepts/objects.md#pagkapit).

**Plugin.** Ang WorldEditorBridge, ang BepInEx plugin ng editor sa laro o server na nagho-host ng mundo. Hinahayaan
nito ang editor na basahin at baguhin ang tumatakbong mundo. Tingnan ang
[I-install ang editor](../start/install.md#ang-plugin-para-sa-live-na-pag-edit).

**Prefab.** Ang panloob na pangalan ng laro para sa isang uri ng object, gaya ng `Beech1` o `woodwall`. Tinatanggap
ito ng mga paghahanap.

**Save (may numero).** Iniingatan ng laro ang isang mundo bilang mga save na may numero (`_main.<n>.*`); isinusulat
ng **I-save sa mundo** ang susunod at sinusuri ito. Tingnan ang
[Pag-save ng mundo](../concepts/saving-and-history.md#pag-save-ng-mundo).

**`savedir`.** Ang folder kung saan iniingatan ng dedicated server ang mga mundo nito (ang opsiyong `-savedir` nito);
nasa `<savedir>/worlds_local` ang mga mundo nito. Tingnan ang
[Magbukas ng mundong wala sa listahan](../guides/open-a-world.md).

**Seed.** Ang salitang pinagmulan ng isang mundo: ang parehong seed ay nagbibigay ng parehong kalupaan, mga biome at
mga lokasyon. Tingnan ang [Isang bagong mundo](../new-world.md).

**Spawn point.** Isang di-nakikitang object ng laro kung saan lumilitaw ang mga creature. Tingnan ang
[Mga spawn point](../concepts/objects.md#mga-spawn-point).

**Stamp.** Isang hugis ng brush na gawa sa larawan ng taas: nagpipinta ka gamit ito. Inilalagay ng tool na
[Lupain](../landform.md#larawan) ang parehong mga larawan nang buo sa lupa, sa isang click. Tingnan ang
[Lilok at pintura](../terrain.md#mga-stamp).

**Sundan.** Isang switch sa top bar: kusang lumalaki ang area kapag tumingin ka malapit sa gilid nito. Tingnan
ang [Sundan](../concepts/areas-and-zones.md#sundan).

**Suri ng suporta.** Ang mga kulay ng Gawaan para sa kung gaano katatag ang pagkakasuporta sa bawat piece, gaya sa
build mode ng laro. Tingnan ang [Ang suri ng suporta](../concepts/objects.md#ang-suri-ng-suporta).

**Token.** Ang lihim ng plugin, sa `BepInEx/config/Tie.WorldEditorBridge.cfg`, na dapat ibigay ng editor para
kumonekta. Tingnan ang [Paano ito kumokonekta](../concepts/live-editing.md#paano-ito-kumokonekta).

**Tool na Rehiyon.** Ang tool (`B`) na pumipili ng kahon o polygon ng lupa para patagin, pintahan, kopyahin o ibalik,
o para piliin ang mga object sa loob nito para sa tool na Pagpili. Iba ito sa **Area**, ang bloke ng mga zone na
nakabukas sa 3D. Tingnan ang [Rehiyon, kopyahin at i-paste](../area.md).

**Tool na Tanaw.** Ang tool (`Esc` o `H`) para tumingin-tingin at pumili ng mga object nang walang binabago. Iba ito
sa panel na **Tanaw** (`V`). Tingnan ang [Ang window ng editor](../editor-basics.md#ang-tool-rail).

**Tunnel.** Ang encrypted na SSH connection na binubuksan ng editor para maabot ang plugin sa isang dedicated server.
Tingnan ang [I-edit ang dedicated server habang may naglalaro](../guides/edit-a-server-live.md).

**Walang limitasyon.** Isang switch sa card na Mask na hinahayaan ang mga tool sa lupa na igalaw ang lupa lampas sa 8 m
na hangganan ng laro, sine-save bilang mga ground disc. Tingnan ang
[Walang limitasyon](../concepts/ground-limits.md#walang-limitasyon).

**Zone.** Isang 64 × 64 m na parisukat ng mundo, ang yunit na nilo-load at sine-save ng laro. Tingnan ang
[Mga zone](../concepts/areas-and-zones.md#mga-zone).

**Zone na na-reset.** Isang zone na minarkahan para gawin ito ulit ng laro mula sa simula sa susunod na pag-load nito.
Tingnan ang [Buuin ulit ang mga zone](../guides/reset-zones.md).
