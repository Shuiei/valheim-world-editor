# Ilipat o kopyahin ang isang gusali

Ilipat ang isang bahay, kasama ang lahat ng nasa loob nito, nang ilang metro o sa kabilang dulo ng mundo, o maglagay ng
kopya nito sa ibang lugar.

**Kailangan mo:** isang mundong bukas sa editor, nakabukas ang area sa paligid ng gusali (mag-backup muna: tingnan ang
[Mag-backup ng mundo](back-up-a-world.md)).

## Mga hakbang

1. Pindutin ang `E` para buksan ang [Pagpili](../select.md).
2. I-double-click ang isang pader ng gusali: napipili ang bawat nakakonektang piece, pati ang mga chest at muwebles sa
   mga sahig nito.
3. Opsiyonal: para isama ang mga nakahiwalay na object sa loob (isang mesang nakatayo nang hiwalay), `Ctrl` + click sa
   kanila.
4. Para sa maikling paglipat, i-drag ang isang napiling piece, o i-drag ang isang arrow para ilipat sa isang axis;
   i-drag ang orange na singsing para iikot ito. Panatilihing naka-on ang **Ilapag ang bawat object sa lupa habang
   inililipat**, para nakapatong sa lupa ang gusali kung saan ito lumapag.
5. Para sa mahabang paglipat, pindutin ang `Ctrl+X` (o `Ctrl+C` para sa kopya). Nasa clipboard na ngayon ang gusali.
6. Buksan ang area sa bagong lugar (mula sa [Mapa](../map.md)), o manatili sa area na ito.
7. Pindutin ang `Ctrl+V`: sinusundan ng gusali ang cursor, aninag.
8. Iikot ito gamit ang `R` (isang kapat na ikot) o `,` `.` (ayon sa **Iikot nang** sa bar ng Pagtayo), saka mag-click
   kung saan ito dapat tumayo.
9. Pindutin ang `Esc` para huminto sa pag-paste.
10. I-click ang **I-save sa mundo** (o **I-apply nang live**).

Pinapanatili ng mga kopya at inilipat na piece ang lahat ng hawak nila: laman ng chest, teksto ng karatula, kung sino ang
nagtayo sa kanila. Isinasama ng gusaling na-paste gamit ang `Ctrl+V` ang lupa sa ilalim nito.

## Tingnan kung gumana

Sinasabi ng status bar kung ilang object ang inilipat o na-paste. Tingnan ang gusali mula sa iba't ibang panig: walang
dapat nakalutang o naiwan. Pagkatapos mag-save, buksan ang mundo sa laro at pumasok.

## I-undo ito

- Bago mag-save: binabawi ng `Ctrl+Z` ang paglipat, ang pag-gupit o ang pag-paste (magkahiwalay na hakbang ang isang
  pag-gupit at ang pag-paste nito).
- Pagkatapos mag-save: tingnan ang
  [Mag-undo ng hakbang, bawiin ang isang pagbabago, o itapon ang lahat](undo-changes.md), o
  [Ibalik ang isang area mula sa backup](restore-from-backup.md).

## Mga tip

- Dapat kumasya ang paste sa loob ng bukas na area: kung sinasabi nitong *Hindi na-paste*, magbukas ng mas malaking area
  sa paligid ng lugar.
- Nananatili ang clipboard: makakapag-paste ka sa ibang area o ibang mundo.
- Para ilipat nang eksaktong metro, gamitin ang **EKSAKTONG PUWESTO** → **Ilipat nang** sa panel ng Pagpili.
- Kumakapit ang hinihilang gusali sa mga piece sa loob ng 0.75 m habang **Auto** ang **Kapit** sa
  [bar ng Pagtayo](../build.md#ang-bar-ng-pagtayo). Piliin ang **Libre** para iwan ito nang eksakto kung saan mo ito
  i-drag.
- Para sa barko o iba pang sasakyan ng mod, piliin ang anumang bahagi: gumagalaw ang buong grupo.
- Sa live mode, nananatiling parehong object sa laro ang gusaling inilipat habang walang player na malapit dito, kaya
  patuloy itong nasusubaybayan ng mga mod na sumusubaybay dito: tingnan ang
  [Hindi nagbabago ang object kapag inilipat](../concepts/live-editing.md#hindi-nagbabago-ang-object-kapag-inilipat).
