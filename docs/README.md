# Valheim World Editor help

The Valheim World Editor opens a Valheim world, saved or running, in a 3D window. Shape the ground, build, place and
move anything, then save it back or watch it change in game as you work.

New here? Start with [getting around the editor](editor-basics.md), then open the page of the tool you want to use.
Every page is also in the editor: **Documentation** on the start page.

## Start here

- [Getting around the editor](editor-basics.md): the start page, the window, the camera, the area, saving and undo.
- [The world map](map.md): find a place, open it in 3D, search the whole world.
- [Live mode](live-mode.md): edit your game or a dedicated server while people play.

## Shape the ground

- [Ground tools](terrain.md): sculpt and paint brushes, stamps, the ±8 m limit, No limit, Shape and Mountain.
- [Path](path.md): roads, ramps, rivers and caves along a line.
- [Mask](masks.md): keep any tool to a biome, a height, a slope or a paint.
- [Measure and overlays](measure.md): distances, slopes, slope colours and height lines.

## Objects and areas

- [Place](place.md): trees, rocks, crops, building pieces and spawn points, by brush, line, grid or zone.
- [Select](select.md): pick, move, turn, copy and delete objects, and look inside them.
- [Area, copy and paste](area.md): level, clear, copy and paste a box or polygon, restore it from a backup.

## Build and create

- [The Workshop](workshop.md): build on a blank plot and keep it as a blueprint.
- [Dungeons](dungeons.md): generate a dungeon, or edit the game's rooms one by one.

- [Script](scripting.md): shape, paint and fill an area with C# scripts.
- [Claude](claude.md): let Claude shape the world or build from a prompt.
