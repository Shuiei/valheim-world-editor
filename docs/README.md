# Valheim World Editor help

The Valheim World Editor opens a Valheim world, saved or running, in a 3D window. Shape the ground, build, place and
move anything, then save it back or watch it change in game as you work.

**New here?** [Install the editor](start/install.md), then follow [your first edit](start/first-edit.md): ten minutes
on a copy of a world, nothing to lose. Looking for something? Search the help (`Ctrl+F` in the Help window), or start
from a task below.

> [!IMPORTANT]
> Keep a copy of a world before you change it: see [Back up a world before editing](guides/back-up-a-world.md). The
> editor checks that every save reads back correctly before it lets the old one go, but it keeps no copy of its own.
